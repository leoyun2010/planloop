## 1. 배경 (왜 바꾸는가)

- 영업은 로그인하면 BoM 목록부터 보고, 검증할 건·견적 유효기간이 끝나가는 건을 직접 찾아야 했다.
- 엔지니어가 BoM 에 의견을 남길 곳이 없어 메신저로 행 번호를 주고받았다.
- 같은 고객사의 이전 BoM·견적을 찾으려면 목록에서 고객사명을 매번 검색해야 했다(띄어쓰기·대소문자가 다르면 못 찾음).
- 견적을 낸 뒤 결과(수주·실주)를 남길 곳이 없어 수주율을 알 수 없었다.
- 검증에서 Cisco 판매 종료 품목과 대체 SKU 를 알려줘도 사람이 표에서 SKU 를 하나씩 고쳐야 했다.
- **구현이 기획보다 앞서 있다.** 구현·테스트 완료(check.ps1 ALL PASS, E2E 14건 통과, 마이그레이션 0011). 이 CR 은 승인 문서를 구현에 맞추는 역반영이다.

#### 2.6 대체 SKU로 바꾸기 (DEC-75 ⑥) — SCR-007 보완

| 항목 | 내용 |
|---|---|
| 대상 행 | 최신 검증의 EOS 결과에서 **Cisco** 행 중 상태가 판매 종료·EoS 예정이고, 대체 SKU 가 Cisco SKU 형식(R3)에 맞으며 지금 SKU 와 다른(대소문자 무시) 행. Dell 은 제품 품명으로 조회해 행 SKU 와 맞지 않아 뺀다 |
| 버튼 | SCR-007 머리 [대체 SKU {n}] — **작성자에게만**, 대상이 1행 이상일 때 |
| 모달 「대체 SKU로 바꾸기」 | 안내 「판매 종료·EoS 예정 품목의 SKU 를 EOS 검색 결과의 대체 SKU 로 바꿉니다. List 단가·수량·품명은 그대로이니 바꾼 뒤 확인하고 다시 검증하세요.」, 행마다 체크박스(처음엔 모두 체크) 「행 {n} · {SKU} → {대체 SKU}」 + 상태 칩, [닫기]·[{n}행 바꾸기] |
| 확정 버전 | 체크박스·버튼 비활성 + 「작성중 버전에서만 바꿀 수 있습니다. BoM 화면에서 [새 버전]을 만든 뒤 다시 검증하세요.」 |
| 확인 | 「{n}행의 SKU 를 대체 SKU 로 바꿀까요? 검증 결과는 「재검증 필요」가 됩니다.」 [바꾸기] |
| 처리 | **행 저장(POL-005·020)과 같은 규칙** — revision 확인(충돌 시 기존 문구), SKU 만 바꾸고 List 단가·수량·품명·구분·상위 관계는 그대로, 수정됨 표시·원본 값 유지, 검증 상태 「재검증 필요」. `POST /api/versions/{id}/replace-skus {revision, rowIds}` |
| 결과 | 토스트 「{n}행의 SKU 를 바꿨습니다. List 단가를 확인하고 다시 검증하세요.」. 고른 행 중 대상이 아닌 행이 있거나 대상이 0이면 400 「바꿀 수 있는 행이 없습니다. 최신 검증 결과를 다시 확인하세요.」(전부-아니면-전무) |
| 감사 | 「대체 SKU 적용」 `SKU_REPLACE` (대상 버전, extra `rows` = 행 수) |

#### 2.7 견적 결과 · 수주율 · 유효기간 임박 (DEC-75 ④⑤) — SCR-009 보완

| 항목 | 내용 |
|---|---|
| 견적 결과 | SCR-009 견적 목록·머리에 선택 상자 「기록 전 / 제출 / 수주 / 실주」. 고르면 **바로 저장**(별도 [저장] 아님). 안내 「고객에게 낸 뒤 결과를 기록하면 내 현황에서 수주율과 유효기간 임박 견적을 볼 수 있습니다.」 |
| 저장 성격 | 견적 내용이 아니다 — 견적의 revision·수정 시각을 바꾸지 않아 편집 중인 입력과 충돌하지 않는다. 결과를 바꾼 시각(`outcome_at`)만 남긴다 |
| 권한 | 작성자만(견적 권한과 같음). `PUT /api/quotes/{id}/outcome {outcome: null\|"SUBMITTED"\|"WON"\|"LOST"}`. 다른 값은 400 「견적 결과 값이 올바르지 않습니다.」 |
| 감사 | 「견적 결과 기록」 `QUOTE_OUTCOME` (extra `outcome`) |
| 수주율 | 수주 ÷ (수주 + 실주) × 100, 반올림 정수 %. 수주 + 실주 = 0 이면 「-」 |
| 유효기간 끝 | 견적서 머리(SCR-010)를 **저장한** 견적만 — 견적일자 + 유효기간(일). 머리를 저장하지 않은 견적은 유효기간을 모른다 |
| 유효기간 임박 | 유효기간 끝이 오늘 ~ 7일 뒤이고 결과가 수주·실주가 아닌 견적(기록 전·제출) |
| BoM 건 복제·이전 버전 견적 가져오기 | 결과는 옮기지 않는다(새 견적은 기록 전) |
