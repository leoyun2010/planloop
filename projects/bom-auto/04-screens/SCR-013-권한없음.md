# 화면정의서 — SCR-013 권한 없음 안내

| 항목 | 내용 |
|---|---|
| 화면 ID | SCR-013 |
| 문서 버전 | v1.0 |
| 상태 | 승인 |
| 경로(URL) | `/403`, `/404` (원래 URL은 주소창에 그대로 두고 이 화면을 렌더링해도 된다) |
| 접근 권한 | 로그인 사용자 (영업·엔지니어·관리자). 역할 미지정은 SCR-002, 미인증은 SCR-001 |
| 진입 경로 | 권한 없는 화면 URL 직접 접근(예: 엔지니어가 견적 URL), API 403 수신, 없는 BoM·버전·견적 주소 |
| 관련 요구사항 | REQ-002, REQ-015 |
| 관련 정책 | POL-008, POL-009 |
| 관련 테스트 | TC-013, TC-112, TC-151, TC-159 |
| HTML 목업 | [SCR-013-권한없음.html](SCR-013-권한없음.html) |

## 1. 화면 목적

- 쓸 수 없는 기능이나 없는 주소에 들어온 사용자에게 이유를 알리고 BoM 목록으로 돌려보낸다.

## 2. 레이아웃 (텍스트 와이어프레임)

```
+--------------------------------------------------------------+
| [1] GNB (역할에 맞는 메뉴)                                    |
+--------------------------------------------------------------+
|                                                              |
|                  [2]  ( ! )                                  |
|                  이 기능을 사용할 권한이 없습니다.            |
|                                                              |
|                  [3] [BoM 목록으로]                           |
|                                                              |
+--------------------------------------------------------------+
```

## 3. 컴포넌트 트리 (개발 인수인계용)

```jsx
<ErrorPage kind={"forbidden" | "notFound"}>
  <GNB />                                           {/* [1] 공통 — 역할에 맞는 메뉴만 */}
  <ErrorMessage                                     /* [2] */
    text={kind === "forbidden"
      ? "이 기능을 사용할 권한이 없습니다."           /* POL-008 */
      : "요청한 페이지를 찾을 수 없습니다."} />       {/* IA 4.1 */}
  <Button onClick={() => goto("/boms")}>BoM 목록으로</Button>   {/* [3] → SCR-003 */}
</ErrorPage>
```

## 4. 구성 요소 정의

| # | 요소 | 유형 | 내용/동작 | 관련 정책 |
|---|---|---|---|---|
| 1 | GNB | 공통 | 03-ia.md 공통 UI. 활성 메뉴 없음 | POL-008 |
| 2 | 안내 문구 | 텍스트 | 403: 「이 기능을 사용할 권한이 없습니다.」 / 404: 「요청한 페이지를 찾을 수 없습니다.」 | POL-008 |
| 3 | [BoM 목록으로] | 버튼 | SCR-003으로 이동 | |

## 5. 상태별 화면

| 상태 | 조건 | 표시 내용 |
|---|---|---|
| 기본 (403) | 권한 없는 기능 | [2] 403 문구 + [3] |
| 변형 (404) | 없는 BoM·버전·견적·주소 | [2] 404 문구 + [3] |
| 로딩 | 해당 없음 | 서버가 판정한 결과를 바로 보여주는 정적 화면이다 |
| 빈 상태 | 해당 없음 | 조회할 데이터가 없다 |
| 에러 | 해당 없음 | 이 화면 자체가 오류 안내 화면이다 |

- 403과 404는 구분해서 보여준다. 단, 다른 영업의 견적 URL처럼 **존재 여부 자체가 가격·견적 정보**인 경우에는 404가 아니라 403을 보여준다. 이렇게 하면 견적이 있는지 없는지를 비작성자가 알아낼 수 없다 (POL-009).

## 6. 입력 유효성 (입력 폼이 있는 경우)

해당 없음 — 입력 폼이 없다.

## 7. 인터랙션 상세

- 화면 URL 권한 검사에서 걸리면 서버가 이 화면(403)을 렌더링한다. 화면 안에서 API가 403을 반환하면 클라이언트가 이 화면으로 이동한다 (POL-008).
- [BoM 목록으로] → `/boms` (SCR-003).
