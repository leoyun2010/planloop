## 1. 화면 목적

- 한 버전의 표준 BoM을 계층 표로 보여준다. 작성자는 작성중 버전을 셀 단위로 고치고 저장·검증까지 할 수 있다. 누구나 표준 BoM xlsx를 내려받을 수 있다.

## 3. 컴포넌트 트리 (개발 인수인계용)

```jsx
<BomDetailPage bomId versionNo>                     {/* GET /api/boms/{id}/versions/{n} — 비작성자 응답엔 가격 필드 없음 (POL-009) */}

    validationState={v.validationState} />          {/* 미검증 | 검증 완료 | 재검증 필요 (POL-004) */}
  <BomTabs active="bom" showQuote={isAuthor} />     {/* [3] 견적 탭은 작성자만 (POL-008) */}
  <Toolbar>                                         {/* [4] */}
    {canEdit && <>                                  {/* canEdit = isAuthor && v.status === "작성중" (POL-004, POL-008) */}
      <Button onClick={openPanel("SCR-006")}>파일 올리기</Button>
      <Button onClick={addRowBelowSelected}>행 추가</Button>          {/* POL-020 행 추가 */}
      <Button disabled={!selected.length} onClick={confirmDelete}>선택 행 삭제</Button>  {/* → [8] */}
      <Button disabled={!dirty} onClick={save}>저장</Button>          {/* PUT rows + revision (POL-005) */}
      <Button disabled={rows.length === 0} onClick={validate}>검증</Button> {/* → SCR-007 (POL-021) */}
    </>}
    {isAuthor && v.status === "확정" && v.isLatest && <Button onClick={createVersion}>새 버전 만들기</Button>} {/* POL-004 */}
    {(role === "영업" || role === "관리자") && v.status === "확정" &&
      <Button onClick={openDialog("clone")}>BoM 건 복제</Button>}     {/* → [12] 작성자가 아니어도 (POL-048, DEC-66) */}

    {isAuthor && !bom.hasConfirmed && <DangerButton onClick={confirmDeleteBom}>BoM 건 삭제</DangerButton>} {/* → [11] */}
  </Toolbar>

    rows={v.rows}

    editable={canEdit}
    lockedFields={LOCKED}                           /* POL-020: 행 번호·원본 라인·원본 파일·원본 행·행 유형·EOS·벤더 Net */
    onCellEdit={checkCellEdit}                      /* POL-020 숫자 검사, POL-019 onEdit(List 금액 재계산) */
    modifiedMark={cell => cell.value !== cell.original}  /* 「수정됨」 + tooltip 「원본 값: {값}」 */
    highlightRowId={query.row} />

  <ConfirmDialog id="delete-rows" />                {/* [8] POL-020 문구 */}
  <LeaveGuard when={dirty} />                       {/* [9] POL-005 이탈 확인 */}
  <ConflictDialog />                                {/* [10] STALE_REVISION (POL-005) */}

</BomDetailPage>
```

## 7. 인터랙션 상세

- **셀 편집**: 셀 클릭 → 입력칸 → Enter·포커스 이동으로 확정 → [7] 「저장하지 않은 변경 {n}건」 증가. 수량·List 단가를 바꾸면 List 금액을 `List 단가 × 수량`으로 바로 다시 계산한다 (POL-019). 상위 행 번호를 바꾸면 행 유형이 바뀐다(빈 값 → 상위 품목, 값 있음 → 구성품).
- **행 추가**: 선택한 행 바로 아래(선택이 없으면 맨 아래)에 빈 행을 넣는다. 원본 파일명은 「직접 입력」이다 (POL-020).
- **저장**: `PUT /api/versions/{id}/rows {revision, changes}` → 성공 시 수정 번호 +1, 검증 상태 「재검증 필요」(이미 검증했다면), 토스트 「저장했습니다.」 → 409면 [10] (POL-005).
- **검증**: `POST /api/versions/{id}/validations` → SCR-007로 이동해 진행 상태를 보여준다 (POL-021).
- **새 버전 만들기**: `POST /api/boms/{id}/versions` → `/boms/{id}/v/{n+1}`(작성중·미검증)로 이동. 거부되면 토스트로 POL-004 문구 「작성 중인 버전(v{n})이 이미 있습니다.」
- **BoM 다운로드**: `GET /api/versions/{id}/bom.xlsx` → 파일명 `{고객사명}_{건명}_BoM_v{n}.xlsx`(POL-007). 가격 정보가 없고, 작성중이면 상단에 「미확정」이 들어간다 (POL-039). 감사 로그를 남긴다 (POL-011).
- **BoM 건 복제**: [12] [복제] → `POST /api/boms/{id}/clone {versionNo, customer, title}` → 새 계보 ID 로 v1 작성중·미검증 건을 만든다. 원본 작성자면 가격 정보·원본 파일(실제 파일 복사)·솔루션 합계까지, 그 밖의 사람은 구성만 가져온다(서버가 판단, POL-009). 감사 로그 「BoM 건 생성」에 복제 원본(`cloneOf`)을 남긴다 (POL-011, POL-048, DEC-66). 400이면 칸 아래 문구, 그 밖의 실패는 대화상자 안에 문구.
- **SCR-007에서 행 클릭으로 들어오면** `?row=` 행으로 스크롤하고 행을 3초간 강조한다.
