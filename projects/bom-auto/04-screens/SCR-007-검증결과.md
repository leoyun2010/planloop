## 1. 화면 목적

- 한 버전의 고정 규칙·EOS·AI 검토 결과를 보여준다. 작성자는 경고·권고를 확인한 뒤 확정한다. 누구나 같은 결과를 xlsx 리포트로 받을 수 있다.

## 3. 컴포넌트 트리 (개발 인수인계용)

```jsx
<ValidationPage bomId versionNo>                   {/* GET /api/versions/{id}/validations/latest */}
  <GNB active="boms" />                            {/* [1] */}
  <BomHeader />                                    {/* [2] 공통 */}
  <BomTabs active="validation" showQuote={isAuthor} />  {/* [3] */}
  <RunBar                                          /* [4] */
    lastRunAt versionNo revision
    canRun={isAuthor && v.status === "작성중" && v.rows.length > 0 && !running}   /* POL-021 */
    onRun={() => POST(`/api/versions/${v.id}/validations`)}
    onDownload={() => GET(`/api/validations/${val.id}/report.xlsx`)} />             {/* POL-039, POL-007 */}
  {running && <ProgressSteps steps={["고정 규칙 검사 중", `EOS 조회 중 (${done}/${total})`, "AI 검토 중"]} />}  {/* [5] POL-021 */}
  {val.state === "재검증 필요" && <StaleBanner />}  {/* [6] 「BoM이 수정되어 이 결과는 최신이 아닙니다」 */}
  <GradeSummary counts ackProgress />              {/* [7] 등급 라벨 텍스트+톤 (NFR-009) */}
  <FindingFilters grade rule aiCategory />         {/* [8] */}
  <FindingTable                                    /* [9] 정렬 POL-021: 등급→행 번호→규칙 ID */
    rows={val.findings}
    ackable={f => f.grade === "경고" && canAck}    /* canAck = isAuthor && v.status === "작성중" */
    authorDetail={isAuthor}                        /* R4·R9 금액 상세는 작성자만 (POL-025, POL-030) */
    onRowClick={f => goto(`/boms/${bomId}/v/${n}?row=${f.rowId}`)} />   {/* → SCR-005 */}
  <AiRecommendations                               /* [10] POL-031 */
    disclaimer="AI가 생성한 권고이며 틀릴 수 있습니다"
    status={val.ai.ok ? "ok" : "failed"}
    onRetry={retryAi}                              /* 수정 번호 다르면 MSG_REVALIDATE */
    ackable={canAck} />
  {isAuthor && v.status === "작성중" &&
    <ConfirmBar                                    /* [11] canConfirm (POL-032) — 비활성 사유 툴팁 */
      showSkipAi={!val.ai.ok}                      /* 「AI 검토 없이 확정합니다」 */
      onConfirm={openDialog("confirm")} />}
  <ConfirmDialog id="confirm" />                   {/* [12] POL-032 문구 → POST /confirm */}
</ValidationPage>
```

## 7. 인터랙션 상세

- **검증 실행**: SCR-005 또는 [4] [검증] → `POST /api/versions/{id}/validations` → [5]가 진행 상태를 보여준다(폴링). 끝나면 [7] ~ [10] 갱신. 검증 중에 다른 창에서 저장되면 결과가 「재검증 필요」로 끝난다 (POL-021).
- **확인함 체크**: `PUT /api/validations/{id}/findings/{fid}/ack` → 「{이름} {일시}」 표시, [7]의 확인 수 증가. 감사 로그 「확인함 체크·해제」 (POL-011). 재검증하면 규칙 ID·행·필드·문구가 같은 판정의 체크는 이어받는다. AI 권고는 이어받지 않는다 (POL-021).
- **AI 다시 시도**: `POST /api/validations/{id}/ai-retry` → AI 단계만 다시 실행한다. 수정 번호가 바뀌었으면 「BoM이 수정되었습니다. 다시 검증해 주세요.」 (POL-031).
- **확정**: [확정] → [12] → `POST /api/versions/{id}/confirm {skipAi}` → 409면 사유 문구를 토스트로 띄운다 → 성공 시 버전 상태 「확정」, 토스트 「v{n}을 확정했습니다.」, SCR-005(확정) 이동 (POL-032).
- **판정 행 클릭**: `/boms/{id}/v/{n}?row={rowId}` (SCR-005, 해당 행 강조).
