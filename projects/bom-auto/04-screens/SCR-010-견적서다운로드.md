| 항목 | 내용 |
|---|---|

| 문서 버전 | v1.0 |
| 상태 | 승인 |

## 1. 화면 목적

- 견적서 양식(단일 표형 / Summary + 세부 시트형)과 파일 형식(xlsx / PDF)을 고르고, 견적서 머리의 부대 문구를 넣어 고객 견적서를 내려받는다.

## 3. 컴포넌트 트리 (개발 인수인계용)

```jsx
<QuoteDocModal quote onClose>                       {/* [1] */}
  <RadioGroup name="form" options={["single", "summary"]} labels={["단일 표형", "Summary + 세부 시트형"]} />  {/* [2] POL-037 */}
  <RadioGroup name="type" options={["xlsx", "pdf"]} />                                                        {/* [3] D-25 */}
  <HeaderFields                                     /* [4] 견적마다 저장 (D-33, POL-037 입력 항목 표) */
    date={{default: today}}
    title={{default: bom.title, max: 100, required: true}}
    to={{max: 50}} cc={{max: 50}}
    validDays={{default: 14, int: [1, 90]}}
    paymentTerms={{default: "계산서 발행 후 60일 이내", max: 100}}
    warranty={{default: warrantyDefault(rows), max: 50, onlyFor: "summary"}}   /* SERVICE 기간 최빈값 → 「{n}년」/「{n}개월」 */
    owner={{readOnly: `${me.name} · ${me.email}`}} />
  {form === "summary" && <DetailTexts tops={topRows} max={500} default={t => t.name} />}  {/* [5] */}
  <DocSummary lines={lines(quote, rows)} total={docTotal} vat={vatIncluded} />            {/* [6] POL-037 */}
  {excludedWithAmount > 0 && <Warn code="MSG_EXCLUDED_HAS_AMOUNT" n={excludedWithAmount} />}  {/* [7] 차단 아님 */}
  <Footer>                                          {/* [8] */}
    <Button onClick={onClose}>취소</Button>
    <PrimaryButton disabled={lines.length === 0} loading={building}
      onClick={() => saveHeader().then(() => GET(`/api/quotes/${id}/document?form=${form}&type=${type}`))} />
  </Footer>
</QuoteDocModal>
```

## 4. 구성 요소 정의

| # | 요소 | 유형 | 내용/동작 | 관련 정책 |
|---|---|---|---|---|
| 1 | 제목 + 닫기 | 텍스트·버튼 | 「견적서 다운로드」. 생성 중에는 닫기 비활성 | |
| 2 | 양식 | 라디오 | 「단일 표형」(기본값) / 「Summary + 세부 시트형」. 마지막으로 고른 양식을 견적에 저장해 다음에 기본값으로 쓴다 | POL-037 |
| 3 | 형식 | 라디오 | 「xlsx」(기본값) / 「PDF」 | POL-037 |
| 4 | 머리 입력 | 입력 폼 | 견적일자(기본 오늘), 견적명(기본 BoM 건명), 수신, 참조, 유효기간(일), 결제조건, 무상유지보수(Summary형일 때만 보임), 담당자(작성자 이름·메일, 읽기 전용) | POL-037 |
| 5 | 상세 내역 | 입력 목록 | Summary형일 때만 보인다. 상위 품목마다 「{NO}. {품명}」 라벨과 입력칸(기본값 = 상위 품목 품명) | POL-037 |
| 6 | 요약 | 텍스트 | 「품목 {n}행 (제외 {m}행) · 합계 {합계}원 (VAT 별도)」. Summary형이면 「VAT 포함 {합계 + floor(합계 × 0.1)}원」을 덧붙인다. 합계는 SCR-009 견적서 합계와 같다 | POL-036, POL-037 |
| 7 | 제외 금액 경고 | 경고 | 제외 행 중 견적가가 0원이 아닌 행이 있을 때: 「견적서에서 제외한 행 중 금액이 있는 행이 {n}개 있습니다. 이 금액은 견적서 합계에서 빠집니다.」 다운로드는 막지 않는다 | POL-037 |
| 8 | [취소] / [다운로드] | 버튼 | [다운로드]는 [4]·[5] 값을 견적에 저장한 뒤 파일을 만든다. 파일명 `{고객사명}_{건명}_견적서_v{n}.{xlsx|pdf}`. 제외 후 품목이 0행이면 비활성 | POL-007, POL-037 |

## 5. 상태별 화면

| 상태 | 조건 | 표시 내용 |
|---|---|---|
| 기본 | 단일 표형 · xlsx | [5]·무상유지보수 숨김, [6]에 VAT 별도 합계만 |
| 변형 — Summary형 | Summary + 세부 시트형 선택 | 무상유지보수·[5] 표시, [6]에 VAT 포함 합계 추가 |
| 로딩 | 파일 생성 중 | [8] 「⟳ 다운로드」 비활성, 입력 읽기 전용, [1] 닫기 비활성 |
| 빈 상태 | 제외 후 품목 0행 | [6] 「견적서에 넣을 품목이 없습니다. 견적서 제외를 해제해 주세요.」, [다운로드] 비활성 |
| 에러 — 입력 오류 | 6장 검사 실패 | 해당 입력칸 아래 문구, [다운로드] 차단 |
| 에러 — 생성 실패 | 금지 값 검사 실패·서버 오류 | 「견적서를 만들지 못했습니다. 관리자에게 문의해 주세요.」 / 감사 로그 기록 실패면 「요청을 처리하지 못했습니다. 잠시 후 다시 시도해 주세요.」 |

## 6. 입력 유효성 (입력 폼이 있는 경우)

| 필드 | 필수 | 형식/제한 | 실패 시 문구 | 관련 정책 |
|---|---|---|---|---|
| 견적일자 | Y | 날짜 | — (날짜 선택기) | POL-037 |
| 견적명(프로젝트명) | Y | 1~100자 | 「견적명은(는) 100자 이내로 입력해 주세요.」 / 비었을 때 「견적명을 입력해 주세요.」 | POL-037 |
| 수신 / 참조 | N | 각 0~50자 | 「수신은(는) 50자 이내로 입력해 주세요.」 / 「참조은(는) 50자 이내로 입력해 주세요.」 | POL-037 |
| 유효기간 | Y | 1~90 정수 | 「유효기간은 1~90일 사이 정수여야 합니다.」 | POL-037 |
| 결제조건 | N | 0~100자 | 「결제조건은(는) 100자 이내로 입력해 주세요.」 | POL-037 |
| 무상유지보수 | N (Summary형) | 0~50자 | 「무상유지보수은(는) 50자 이내로 입력해 주세요.」 | POL-037 |
| 상세 내역 | N (Summary형) | 상위 품목마다 0~500자 | 「상세 내역은(는) 500자 이내로 입력해 주세요.」 | POL-037 |

- 「견적명을 입력해 주세요.」는 POL-003과 같은 형식으로 이 화면에서 처음 쓰는 문구다.

## 7. 인터랙션 상세

- [다운로드] → 입력 검사 → `PUT /api/quotes/{id}/doc-header {revision, form, type, header, details}` → `GET /api/quotes/{id}/document?form=&type=` → 서버가 POL-037 `assertNoForbidden`으로 검사 → 파일 전송 → 모달 닫힘, 토스트 「견적서를 내려받았습니다.」 → 감사 로그(일시·견적 ID·양식·형식, POL-011).
- **생성 규칙(POL-037)**: 단일 표형은 품목 표(제품번호/제품설명/수량/소비자가/공급단가/공급가 합/비고)와 「합계 (VAT 별도)」 1줄이다. Summary형은 Summary 시트(상위 품목 1행씩)와 세부 시트(상위 품목마다 모듈명·상세 내역·수량, 금액 없음), 합계 2줄이다. PDF는 A4 세로이고 표 머리글을 페이지마다 반복하며, 금액은 xlsx와 같다.
- 어느 셀에도 원가·DC율·환율·마진율이 없다. 공급가(합)는 행 견적가, 공급단가는 `floor(견적가 ÷ 수량)`이다 (D-29).
