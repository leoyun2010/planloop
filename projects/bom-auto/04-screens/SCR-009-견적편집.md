## 1. 화면 목적

- 확정 버전 하나를 기준으로 환율·DC율·마진율을 넣어 행별 원가·견적가를 계산하고, 저장한 뒤 고객 견적서와 원가분석표를 내려받는다.

## 3. 컴포넌트 트리 (개발 인수인계용)

```jsx
<QuoteEditPage bomId versionNo quoteId>             {/* 작성자 아니면 403 → SCR-013 (POL-008) */}
  <GNB active="boms" />                             {/* [1] */}
  <BomHeader />                                     {/* [2] */}
  <BomTabs active="quote" showQuote />              {/* [3] */}
  <QuoteSelector                                    /* [4] 한 확정 버전에 견적 여러 개 (POL-033) */
    quotes={v.quotes} onNew={() => POST(`/api/versions/${v.id}/quotes`)}
    basis={`v${v.no} (확정 ${v.confirmedAt})`} />
  <SaveBlockers issues={checkPol033(v, quote)} />   {/* [5] MSG_MISSING_PRICE · MSG_FX_REQUIRED · MSG_PICK_CURRENCY · MSG_BASE_MARGIN_REQUIRED */}
  <FxInputs currencies={nonKrwCurrencies} />        {/* [6] POL-035 checkFx — 0 < x ≤ 100,000, 소수 2자리 */}
  <CategoryDcInputs                                 /* [7] POL-035 applyCategoryDc — 행별 값 덮어쓰면 [13] */
    categories={["PRODUCT", "SERVICE", "SOFTWARE"]} />
  <BaseMarginInput />                               {/* [8] POL-036 checkMargin — 0.0~100.0, 소수 1자리 */}
  <QuoteTable                                       /* [9] 행 = 표준 BoM 행 순서, 계산은 POL-034·036 함수 그대로 */
    rows={v.rows}
    summable={summableRows}                         /* Dell 상위·하위 제품(구성품 있음)은 금액 「—」 */
    bundleIncluded={isBundleIncluded}               /* 「번들 포함」 0원 */
    editable={{unitPriceWhenEmpty: true, currencyWhenEmpty: true, dcRate: true, rowMargin: true, exclude: true}}
    onChange={recalc} />                            {/* 입력 즉시 재계산 (POL-034) */}
  <BulkExcludeAi recs={latestValidation.ai.recommendations.filter(r => r.category === "고객에게 불필요한 항목")} />  {/* [10] POL-037 */}
  <Totals cost={totalCost} price={sumPrice} docTotal={docTotal} />                      {/* [11] */}
  <Actions>                                          {/* [12] */}
    <Button onClick={save} disabled={!dirty}>저장</Button>                               {/* PUT + revision (POL-005) */}
    <Button onClick={openModal("SCR-010")} disabled={dirty || blocked}>견적서 다운로드</Button>
    <Button onClick={download("cost-analysis.xlsx")} disabled={dirty || blocked}>원가분석표 다운로드</Button>  {/* POL-038 */}
  </Actions>
  <ConfirmDialog id="dc-overwrite" />               {/* [13] POL-035 문구 */}
</QuoteEditPage>
```

## 7. 인터랙션 상세

- **재계산**: 어느 입력이든 바꾸면 영향받는 행과 [11]을 즉시 다시 계산한다. 화면과 서버는 같은 함수(POL-034 `costKrw`, POL-036 `quotePrice`)를 쓴다. 원 미만 절사는 행 단위로만 한다.
- **저장**: `PUT /api/quotes/{id} {revision, fx, dcRate, rowMargin, baseMargin, unitPrices, currencyOverride, excluded}` → 저장 조건(POL-033) 검사 → 성공 시 토스트 「저장했습니다.」, 감사 로그 「견적 저장」(POL-011) → 409면 충돌 상태.
- **견적서 제외**: 체크하면 그 행이 견적서 합계에서 빠진다. Dell 상위 품목·하위 제품을 체크하면 그 아래 행도 모두 체크된다 (POL-037).
- **견적서 다운로드**: SCR-010 모달. **원가분석표 다운로드**: `GET /api/quotes/{id}/cost-analysis.xlsx` (POL-038).
- 이 화면의 DC율·단가는 견적에만 저장되고, 표준 BoM 가격 정보는 바뀌지 않는다 (REQ-016).
