## 1. 화면 목적

- 확정 버전 하나를 기준으로 환율·전체 설정·행별 할인율·목표 GP·매입 DC를 넣어 행별 원가·공급단가·GP를 확인하고(계산은 서버, 인성정보 견적서 표준양식 VER1 방식 — DEC-58), 저장한 뒤 고객 견적서를 내려받는다.
- 이전 버전에서 만든 견적의 설정을 새 버전 견적으로 옮길 수 있다(DEC-66).

## 3. 컴포넌트 트리 (개발 인수인계용)

```jsx
<QuotePage bomId versionNo quoteId>                 {/* 작성자 아니면 403 → SCR-013 (POL-008, DEC-62) */}
  <GNB active="boms" />                             {/* [1] */}
  <BomHeader />                                     {/* [2] */}
  <BomTabs active="quote" isAuthor />               {/* [3] */}
  <Toolbar>                                         {/* [4] 한 확정 버전에 견적 여러 개 (POL-033) */}
    <QuoteSelect label={q => `견적 ${q.no} — ${q.updatedAt}`} />
    <Button onClick={() => POST(`/api/versions/${v.id}/quotes`)}>새 견적</Button>
    <ImportQuoteButton />                           {/* 같은 BoM 다른 버전 견적이 있을 때만 — [15] (POL-049) */}
    <Basis text={`기준: v${n} (확정 ${confirmedAt})`} />
  </Toolbar>
  <SaveBlockers blockers={calc.blockers} />         {/* [5] MISSING_PRICE · PICK_CURRENCY · FX_REQUIRED — 행 링크 */}
  <EosBanner flags={eosFlags(calc.rows, docHeader.date, docHeader.validDays)} />  {/* [14] DEC-60 */}
  <FxInputs currencies={calc.currencies} />         {/* [6] 0 < x ≤ 100,000, 소수 2자리 */}
  <QuoteSettings                                     /* [8] 전체 설정 — 표준양식 견적서 시트 머리 (DEC-58) */
    fields={["saleDc", "targetGp", "purchaseDc", "minGp"]} roundUnit={[1, 10, 100, 1000, 10000]} />
  <QuoteTable                                       /* [9] 행 = 표준 BoM 행 순서. 앞 5열 고정, 가로 스크롤 */
    rows={calc.rows}
    inputs={["saleDc", "targetGp", "salePrice", "purchaseDc", "costPrice"]}
    onChange={debounce(300, () => POST(`/api/quotes/${id}/calculate`))} />   {/* 화면은 계산하지 않는다 */}
  <BulkExcludeAi rowIds={aiUnneededRowIds} />       {/* [10] POL-037 */}
  <Totals totals={calc.totals} />                   {/* [11] */}
  <Actions>                                         {/* [12] */}
    <Button onClick={save} disabled={!dirty}>저장</Button>                  {/* PUT + revision (POL-005) */}
    <Button onClick={openModal("SCR-010")} disabled={dirty || blockers || errors}>견적서 다운로드</Button>
  </Actions>
</QuotePage>
```

| 8 | 전체 설정 | 입력 | 「전체 할인율(DC)」·「전체 목표 GP율」·「기본 매입 DC율」·「최소 GP율」(각 %) · 「단가 단위」(1원 / 10원 / 100원 / 1,000원 / 10,000원). 아래에 「행에 입력한 값이 전체 값보다 먼저 쓰입니다. 공급단가 = 판매단가 직접입력 > 행 목표 GP > 행 할인율 > 전체 목표 GP > 전체 할인율 > 소비자가」. 기존 「기본 마진율」은 **폐지(CR-003, DEC-58)** — 이 칸들로 대체 | POL-034 ~ POL-036 |
| 9 | 견적 표 | 표(편집) | 열: 견적서 제외 · 행 번호 · 구분 · SKU · 품명 · 수량 · EOS · 통화 · 소비자가(원) · 할인율 DC(%) · 목표 GP(%) · 판매단가 직접 · 매입 DC(%) · 매입단가 직접 · 원가 단가 · 공급단가 · 적용 · 공급가 합 · GP · GP율 · 실 DC. 앞 5열(견적서 제외 ~ 품명)은 고정되고 나머지는 가로로 스크롤한다. 입력 열은 할인율 DC·목표 GP·판매단가 직접·매입 DC·매입단가 직접 5개 — 비우면 [8] 전체 설정을 따른다. 「적용」은 공급단가를 정한 방식(직접입력 / 행 GP / 행 DC / 전체 GP / 전체 DC / 소비자가 / 번들). **소비자가** = ROUND(List 단가 × 환율). List 금액이 빈 합산 대상 행은 소비자가 칸이 입력칸이다(견적에만 저장). 통화가 빈 행은 통화 선택칸(「선택」·KRW·USD·EUR·JPY·CNY)이 나온다. **원가 단가** = 매입단가 직접 > ROUND(소비자가 × (1 − 매입 DC율)). 공급단가는 단가 단위로 반올림. GP·GP율은 원가가 있는 행만, GP율이 최소 GP율보다 낮으면 GP율 칸을 강조한다. **EOS** 열은 기준 버전 검증의 행 EOS 상태와 End-of-Sale 일자, 저장된 견적일·유효기간과 비교한 「판매 종료」(End-of-Sale < 견적일) / 「유효기간 내 판매 종료」(견적일 ≤ End-of-Sale ≤ 견적일 + 유효기간) 표시(검증 전이면 빈칸). Dell 상위 품목·하위 제품(구성품 있음) 행은 회색이고 금액 칸은 「—」다. Cisco 번들 포함 구성품은 소비자가 칸에 「번들 포함」이고 나머지 칸은 「—」다. 제외한 행은 취소선으로 표시한다 | POL-033 ~ POL-037, DEC-58, DEC-60 |

## 7. 인터랙션 상세

- **재계산**: 어느 입력이든 바꾸면 300ms 뒤 `POST /api/quotes/{id}/calculate`(저장 안 함)로 서버가 다시 계산하고 [9]·[11]·[5]·[14]를 갱신한다. 화면은 계산하지 않는다. 계산은 인성정보 견적서 표준양식 VER1 「견적서」 시트 L ~ X열 수식 그대로다(DEC-58).
- **저장**: `PUT /api/quotes/{id} {revision, fx, settings, rows}` → 저장 조건 검사(실패 409 — 첫 사유 문구) → 성공 시 토스트 「저장했습니다.」, 감사 로그 「견적 저장」(POL-011) → revision 불일치면 충돌 대화상자.
- **견적서 제외**: 체크하면 그 행이 견적서 합계에서 빠진다. Dell 상위 품목·하위 제품을 체크하면 그 아래 행도 모두 제외된다 (POL-037). 제외 행의 원가는 원가 합계에 남는다.
- **이전 버전 견적에서 만들기**: [15] [만들기] → `POST /api/versions/{id}/quotes {fromQuoteId}` → 새 견적을 만든 뒤 고른 견적의 전체 설정·환율·견적서 머리(견적일·상세 내역 뺌)와 행 입력(할인율 DC·목표 GP·판매단가·매입 DC·매입단가·소비자가·통화·견적서 제외)을 계보 ID가 같은 행에 옮긴다. 이번 버전에만 있는 행은 새 견적 기본값, 이번 버전에 없는 행은 {missing}으로 센다. 감사 로그 「견적 만들기」(원본 견적 ID·옮긴 행 수) (POL-049, DEC-66).
- **견적서 다운로드**: SCR-010 모달. **원가분석표 다운로드**(`GET /api/quotes/{id}/cost-analysis.xlsx`)는 **폐지(CR-003, DEC-58)**.
- 이 화면의 입력값은 견적에만 저장되고, 표준 BoM 가격 정보는 바뀌지 않는다 (REQ-016).
