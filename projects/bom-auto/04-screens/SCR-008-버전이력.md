## 1. 화면 목적

- BoM 건의 모든 버전과 상태를 한눈에 보고, 두 버전의 차이를 비교한다. 작성자는 최신 확정 버전에서 새 버전을 만든다.

## 2. 레이아웃 (텍스트 와이어프레임)

```
+--------------------------------------------------------------------------------------------+
| [1] GNB                                                                                    |
| [2] 대웅제약 · 마곡 C&D 센터 구축 … [v2 작성중 ▾] (작성중)(재검증 필요)                     |
| [3] | 표준 BoM | 검증 결과 | 버전 이력 | 견적 |                                                |
| [4] [새 버전 만들기] (비활성: 작성 중인 버전(v2)이 이미 있습니다.)                             |
| [5] | 비교 | 버전 | 상태   | 확정 일시        | 확정자 | 오류 | 경고 | 권고 |          |      |
|     | [v]  | v2   | 작성중 | -                | -      | 0    | 1    | 0    | [열기] | [BoM 다운로드] |
|     | [v]  | v1   | 확정   | 2026-10-02 16:40 | 김영업 | 0    | 2    | 3    | [열기] | [BoM 다운로드] |
| [6] [선택한 두 버전 비교]   (2개를 고르면 활성)                                              |
| [7] v1 → v2 : 추가 1행 · 삭제 0행 · 변경 2행                                                |
|     | 구분 | 행(v1→v2) | 원본 라인 | SKU              | 필드 | v1 값 | v2 값 |                 |
|     | 변경 | 18 → 18   | 2.0       | C9200L-48P-4X-E  | 수량 | 6     | 8     |                 |
|     | 추가 | - → 37    | (직접 입력)| CAB-AC-C15-KOR  | -    | -     | (새 행)|                |
+--------------------------------------------------------------------------------------------+
```

## 3. 컴포넌트 트리 (개발 인수인계용)

```jsx
<VersionHistoryPage bomId>                         {/* GET /api/boms/{id}/versions */}
  <GNB active="boms" />                            {/* [1] */}
  <BomHeader />                                    {/* [2] */}
  <BomTabs active="versions" showQuote={isAuthor} />  {/* [3] */}
  {isAuthor &&
    <CreateVersionButton                           /* [4] canCreateVersion (POL-004) — 비활성 사유 툴팁 */
      onClick={() => POST(`/api/boms/${bomId}/versions`).then(v => goto(`/boms/${bomId}/v/${v.no}`))} />}
  <VersionTable                                    /* [5] 최신 버전이 위 */
    columns={["비교", "버전", "상태", "확정 일시", "확정자", "오류", "경고", "검토 권고", "열기", "BoM 다운로드"]}
    maxCompare={2}
    onOpen={v => goto(`/boms/${bomId}/v/${v.no}`)}          /* → SCR-005 */
    onDownload={v => GET(`/api/versions/${v.id}/bom.xlsx`)} />   {/* POL-039, POL-007 */}
  <CompareButton disabled={selected.length !== 2} />         {/* [6] */}
  {compare &&
    <CompareResult                                 /* [7] 계보 ID로 행을 맞춘다 (POL-004) */
      from={older} to={newer}
      showPriceFields={isAuthor} />}               {/* 가격 필드 차이는 작성자만 (POL-009) */}
</VersionHistoryPage>
```

## 4. 구성 요소 정의

| # | 요소 | 유형 | 내용/동작 | 관련 정책 |
|---|---|---|---|---|
| 1 | GNB | 공통 | 03-ia.md 공통 UI | |
| 2 | BoM 건 헤더 | 공통 | 03-ia.md 공통 UI | POL-004 |
| 3 | BoM 건 탭 | 공통 | [버전 이력] 활성 | POL-008 |
| 4 | [새 버전 만들기] | 버튼 | **작성자에게만** 표시한다. 최신 버전이 확정일 때만 활성이다. 비활성이면 사유 툴팁: 최신이 작성중이면(확정한 적 없는 v1 포함) 「작성 중인 버전(v{n})이 이미 있습니다.」(D-39) | POL-004 |
| 5 | 버전 목록 | 표 | 최신 버전이 위. 열: 비교 체크 · 버전 · 상태(작성중/확정) · 확정 일시 · 확정자 · 오류·경고·검토 권고 건수(최신 검증 기준, 미검증이면 「-」) · [열기](SCR-005) · [BoM 다운로드]. 비교 체크는 2개까지 고를 수 있고, 3번째를 고르면 가장 먼저 고른 것이 풀린다 | POL-004, POL-039 |
| 6 | [선택한 두 버전 비교] | 버튼 | 2개를 골랐을 때만 활성이다. 비활성이면 옆에 「비교할 버전 2개를 선택하세요.」를 표시한다 | |
| 7 | 비교 결과 | 요약·표 | 「v{a} → v{b} : 추가 {n}행 · 삭제 {n}행 · 변경 {n}행」. 표 열: 구분(추가/삭제/변경) · 행 번호(이전 → 이후) · 원본 라인 번호 · SKU · 필드 · 이전 값 · 이후 값. 변경은 필드 하나당 한 줄이다. 번호가 낮은 버전이 항상 「이전」이다. 가격 필드(통화·List 단가·List 금액·할인율) 변경은 **작성자에게만** 보인다. 행 번호만 달라진 경우는 변경으로 치지 않는다 | POL-004, POL-009 |

## 5. 상태별 화면

| 상태 | 조건 | 표시 내용 |
|---|---|---|
| 기본 | 버전 2개 이상, 비교 미실행 | [4] ~ [6], [7] 자리에 「비교할 버전 2개를 선택하세요.」 |
| 변형 — 비교 결과 | 두 버전 비교 | [7] 요약과 표. 차이가 없으면 「두 버전의 내용이 같습니다.」 |
| 변형 — 새 버전 가능 | 작성자, 최신이 확정 | [4] 활성 |
| 변형 — 비작성자 | 엔지니어·관리자·다른 영업 | [4] 없음, [7]에 가격 필드 차이 없음 |
| 로딩 | 목록 조회·비교 계산 중 | [5] 스켈레톤 / [7] 스켈레톤, [6] 스피너 |
| 빈 상태 | 버전이 v1 하나뿐 | [5]에 v1 한 행, [6] 비활성, [7] 「비교할 다른 버전이 없습니다.」 |
| 에러 | 조회·비교 실패 | 「데이터를 불러오지 못했습니다. 다시 시도해 주세요.」 + [다시 시도]. 새 버전 생성 실패(서버 오류)는 토스트 「요청을 처리하지 못했습니다. 잠시 후 다시 시도해 주세요.」 |

## 7. 인터랙션 상세

- [새 버전 만들기] → `POST /api/boms/{id}/versions` → 최신 확정 버전의 행·가격 정보를 셀 단위로 복사한 v{n+1}(작성중·미검증) 생성 → 토스트 「v{n+1}을 만들었습니다.」 → SCR-005(v{n+1}) 이동. 409면 POL-004 문구를 토스트로 띄운다. 감사 로그 「새 버전 생성」(POL-011).
- [선택한 두 버전 비교] → `GET /api/boms/{id}/compare?a=&b=` → [7]. URL에 `?compare=a,b`를 남겨 공유할 수 있다.
- 비교는 행의 **계보 ID**로 맞춘다. 새 버전의 행은 복사 원본 행의 계보 ID를 이어받는다. 계보 ID가 한쪽에만 있으면 추가·삭제로 표시한다 (POL-004).
- [BoM 다운로드] → 해당 버전의 표준 BoM xlsx, 파일명 `{고객사명}_{건명}_BoM_v{n}.xlsx` (POL-007, POL-039).
