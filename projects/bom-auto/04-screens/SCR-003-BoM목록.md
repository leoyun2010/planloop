## 1. 화면 목적

- 전사 BoM 건을 조건(고객사명·건명·SKU·벤더·작성자·상태·기간)으로 찾아 상세 화면으로 들어간다.

## 3. 컴포넌트 트리 (개발 인수인계용)

```jsx
<BomListPage>
  <GNB active="boms" />                          {/* [1] 공통 — 사용자 관리·통계·감사 로그·환경설정은 관리자만 (POL-008) */}
  <PageHead title="BoM 목록">                     {/* [2] */}
    {canCreate && <Button onClick={openModal("SCR-004")}>새 BoM</Button>}  {/* canCreate = 영업·관리자 (POL-008 CREATE_BOM, DEC-62) */}
  </PageHead>
  <SearchBar                                     /* [3] 조건 AND 결합, 제출 시 URL 쿼리 갱신 (POL-006) */
    fields={{
      text:   "고객사명·건명 부분 일치",
      sku:    "3자 이상, 최신 버전 개별 SKU 포함 검색",     /* MSG_SKU_MIN3 */
      vendor: ["전체", "Cisco", "Dell"],
      author: "사용자 선택(이름 자동완성)",
      status: ["전체", "작성중", "확정"],
      from, to                                          /* MSG_DATE_ORDER, KST 양 끝 포함 */
    }}
    onReset={clearQuery} />
  {canCreate && <MineToggle />}                  {/* [4] 작성자 = 나 */}
  <ResultSummary total sort="최종 수정일 최신순" />  {/* [5] */}
  <BomTable                                      /* [6] GET /api/boms — 가격 필드 없음 (POL-009) */
    columns={["고객사명", "건명", "벤더", "작성자", "최신 버전·상태", "최종 수정일시"]}
    sort="updatedAt desc, id desc"
    onRowClick={b => goto(`/boms/${b.id}/v/${b.latestVersionNo}`)} />  {/* → SCR-005 */}
  <Pager pageSize={20} />                        {/* [7] POL-006 */}
</BomListPage>
```

## 5. 상태별 화면

| 상태 | 조건 | 표시 내용 |
|---|---|---|
| 기본 | 결과 1건 이상 | [1] ~ [7] |
| 로딩 | 목록 조회 중 | [6] 자리에 스켈레톤 5행, [5] 「조회 중」 |
| 빈 상태 — 전체 0건 | 검색 조건 없이 0건 | 「등록된 BoM이 없습니다.」 + 영업·관리자에게는 [새 BoM] 버튼 |
| 빈 상태 — 검색 0건 | 조건이 있고 0건 | 「조건에 맞는 BoM이 없습니다.」 + [초기화] |
| 에러 | 조회 실패 | 「데이터를 불러오지 못했습니다. 다시 시도해 주세요.」 + [다시 시도] (IA 4.1) |
| 역할 변형 — 관리자 | 관리자 | 영업과 같이 [새 BoM]·[4] 내 BoM만 보기를 표시한다. GNB에 관리자 메뉴([사용자 관리] [통계] [감사 로그] [환경설정])가 더 있다 (DEC-62) |
| 역할 변형 — 엔지니어 | 엔지니어 | [새 BoM]과 [4] 내 BoM만 보기를 표시하지 않는다 |

## 6. 입력 유효성 (입력 폼이 있는 경우)

| 필드 | 필수 | 형식/제한 | 실패 시 문구 | 관련 정책 |
|---|---|---|---|---|
| 고객사명·건명 | N | 자유 텍스트, 앞뒤 공백 무시 | — | POL-006 |
| SKU | N | 비우거나 3자 이상 | 「SKU는 3자 이상 입력해 주세요.」 (검색 실행 안 함) | POL-006 |
| 벤더·상태 | N | 선택 | — | POL-006 |
| 작성자 | N | 사용자 목록에서 선택 | — | POL-006 |
| 최종 수정일 시작·종료 | N | 날짜. 시작 ≤ 종료 | 「시작일이 종료일보다 늦습니다.」 (검색 실행 안 함) | POL-006 |

## 7. 인터랙션 상세

- [검색] → 입력 검사(6장) → 통과 시 URL 쿼리 갱신 → `GET /api/boms?...` → [5]·[6]·[7] 갱신. 뒤로가기로 이전 조건을 되살린다.
- 목록 행 클릭 → `/boms/{id}/v/{최신 버전}` (SCR-005).
- [새 BoM] → SCR-004 모달 → 만들기 성공 시 SCR-005(v1) + SCR-006 패널이 열린 상태로 이동한다.
- 목록과 검색에는 가격 필드가 없다. 가격으로는 검색할 수 없다 (POL-009, REQ-015).
- 관리자가 만든 BoM 건은 관리자가 작성자다. 자기 건은 영업 작성자와 같은 권한(편집·검증·확정·견적·가격 조회)이고, 남의 건 가격·견적은 지금처럼 볼 수 없다 (POL-008, DEC-62).
