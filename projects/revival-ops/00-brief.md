## 1. 한 줄 정의

> **집회 본부 운영팀**이 **대전도집회의 접수·입금·숙소·상담·셔틀 운영을 한 시스템에서 처리**할 수 있게 하고,
> **참가자**가 **로그인 없이 신청하고 자기 상태를 조회**할 수 있게 하는 **웹 기반 집회 운영 시스템**
> (참가자 = 모바일 12화면 / 관리자 = PC 13화면)

## 2. 해결하려는 문제

- **명단이 엑셀에 흩어진다.** 접수를 국내선교팀이 엑셀로 받아 관리해 왔고, 취합·수정 과정에서 중복·누락이 생긴다.
- **입금과 인원이 어긋난다.** 한 신청서에 여러 명이 있는데 각자 따로 입금해 부분 매칭이 발생하고, 대시보드 인원수가 실제와 달라진다. 원인 추적에 오래 걸린다 (P-08 배경).
- **"방금 입금했는데 왜 신청 완료가 안 돼 있냐"는 문의가 매우 많다.** 은행 내역을 모아서 확인하는 방식이라 2~3일이 걸리는데 안내 경로가 없다 (P-07 배경).
- **숙소 배정이 수작업이고 현장 대응이 어렵다.** 거동 불편·동행자·연령을 고려한 배치를 손으로 하고, 현장 불만이 들어와도 바꿀 자리가 즉시 보이지 않는다 (P-11·P-18).
- **상담·셔틀이 전화와 텔레그램으로 돈다.** 상담사별 진행 상황과 셔틀 배차 현황을 한 곳에서 보는 수단이 없다.
- **누가 무엇을 바꿨는지 모른다.** 데이터가 이상해졌을 때 원인을 찾는 데 시간이 오래 걸린다 (P-33 배경).

지금 해결할 가치: 위 문제는 모두 지난 회차(수양회 포함) 운영에서 실제로 발생한 것이고, 담당자가 바뀌어도 같은 판단이 나오도록 기준을 시스템에 넣는 것이 목적이다. 집회는 반복 개최되므로 한 번 만들면 지교회 집회에도 재사용한다 (A2-01).

## 4. 핵심 가치 제안

- **엑셀 + 전화 + 텔레그램 대비**: 접수부터 입금·숙소·상담·셔틀까지 같은 명단 위에서 이어지고, 모든 변경이 담당자·사유와 함께 기록된다.
- **일반 설문 도구 대비**: 정원·버퍼 차단, 사람 단위 입금 매칭, 배정 룰이 시스템 규칙으로 들어가 있어 판단이 담당자에 따라 흔들리지 않는다.
- **운영 기준이 문서로 분리되어 있음**: 정책 36건이 배경·근거와 함께 정리되어 있어, 기준이 바뀌면 영향 기능을 정책ID로 역추적할 수 있다.

## 5. 핵심 기능 (우선순위순)

우선순위 표기는 기능정의서 기준 — 1차(필수) = 이번 집회 운영에 없으면 안 되는 것, 2차(중요) = 운영 편의를 크게 좌우하는 것, 3차(선택).

1. **온라인 접수** [1차] — 4단계 폼(기본정보 → 동행자 → 상태 → 동의), 인도자 동행자 일괄 신청, 개인정보·민감정보 분리 동의, 접수 기간·정원 자동 차단 (U1~U6, A2)
2. **입금 매칭 · 접수/환불 관리** [1차] — 은행 엑셀 업로드, **사람 한 명 단위** 매칭, 등록번호 발급, 취소·환불 처리와 상태별 버튼 분기 (A3, A4)
3. **숙소 배정** [1차] — 배치도 생성, 동행자 인접·거동 불편 1층 우선 배정, 보류 좌석 확보, 현장 좌석 조정 (A6)
4. **명찰 출력** [1차] — 입금 확인 건만 대기열에 올려 전날 일괄 출력, 분실 재발급용 개별 출력 (A5)
5. **상담 운영** [2차] — 본부 접수 → 상담실·상담사 배치 → 타임라인 현황판 → 결과·간증 가능 여부 집계 (A7, A8, A9)
6. **셔틀 관리** [2차] — IN/OUT 방향 분리, 출발 시간 기준 정렬, 본부·셔틀팀 양쪽 배차 (U10, A10)
7. **참가자 마이페이지 · 공지 · 안내문** [1~2차] — 등록번호·입금·숙소·셔틀·상담 상태 통합 조회, 안내문 상시 재열람 (U7~U9, U12, A11)
8. **통합 대시보드 · 계정 권한 · 변경 이력** [2차] — 핵심 지표와 조치 필요 목록, 개인 계정·메뉴 권한, 전 영역 변경 이력 (A1, A12, A13)

전체 규모: 사용자 12화면 + 관리자 13화면 = **25화면 / 162기능 / 데이터항목 132 / 상태값 30 / 정책 36**.

## 6. 성공 기준

- **수기 명단 작업 제로화** — 집회 1회 기준, 시스템 밖(엑셀·카카오톡·종이)에서 별도로 취합하는 명단 **0건**. 전화·현장 접수분도 관리자가 시스템에 대신 입력한다 (A3-03).
- **입금 인원 불일치 0건** — 대시보드 인원 지표와 실제 매칭된 사람 수가 어긋나는 건 0건 (P-08).
- **입금 확인 문의 감소** — 담당자 전화 응대량 감소. 측정 방법·기준값: 미정 — 확인 필요 (P-07 목적).
- 위 항목의 측정 시점과 목표 수치: 미정 — 확인 필요.

## 8. 범위에서 제외하는 것

**1차 출시에서 하지 않기로 결정한 것**

- **온라인 결제·헌금** — 참가비는 계좌이체로 받고 은행 내역 엑셀 매칭으로 처리한다. 카드·간편결제는 넣지 않는다.
- **참가자 회원가입·비밀번호** — 휴대폰 번호 + 이름 확인만 둔다 (P-29).
- **상담 모바일 신청 폼** — 상담은 본부 방문·전화로만 접수하고 사용자 화면에는 연락처만 노출한다 (P-21).
- **현장 접수 창구 운영** — 안내에는 '현장 접수 없음'으로 표기한다. 실제 방문자는 버퍼 좌석으로 관리자가 수동 접수한다 (P-03).
- **셔틀 GPS 실시간 위치 추적** — 운전자 조작 부담이 있어 후순위로 미룬다.
- **집회장 팀장·부팀장 계정 발급** (P-32).

**결정이 남아 범위가 확정되지 않은 것** (기준서 13장 결정 대기 항목 13건 중 범위에 영향을 주는 것)
