## 1. 화면 목적

상담 배치와 숙소·식단 배정에 쓸 구원 여부·건강 상태·숙소 사용 여부를 **인원별로** 받는다. 배정 기준을 미리 알려 현장 불만을 줄인다.

```

|     상태 입력                             |
+------------------------------------------+
| [2] 3단계 · 상태  [===============   ]75% |
| [3] < 1/3명 · 김복음(본인) >   [1][2][3]  |
|                                          |
| [4] 구원 여부 *                           |
|     [ 해결 ][ 재확인 ][ 미해결 ]          |
|                                          |
| [5] 지금 마음 상태 (선택)                 |
|     [                                  ]  |
|                                          |
| [6] 몸 상태 *   [ 불편함 ][ 양호 ]        |
|     알러지 *    [ 있음  ][ 없음 ]         |
|     건강 상세 (선택)                      |
|     [ 예) 무릎 관절염이 있어요          ]  |

|     | 거동 불편 = 1층 우선 (필수 반영)   ||
|     | 지인 근접 배치 = 확약 불가         ||
|     +------------------------------------+|
|                                          |
| [10] [ 이전 ]  [   다음 (2/3명) →      ]  |
```

## 4. 구성 요소 정의

| # | 요소 | 유형 | 내용/동작 | 관련 정책 |
|---|---|---|---|---|
| 1 | 상단 헤더 | 공통 | 「집회 신청 · 3/4」 + 「상태 입력」 | |
| 2 | 단계 진행 바 | 정보 | 3/4단계, 75% | |
| 3 | 인원 전환기 | 내비 | 동행자가 있으면 인원 수만큼 반복. 「{현재}/{전체}명 · {이름}」과 인원 점프 버튼 | |
| 4 | 구원 여부 | 선택(필수) | 해결 / 재확인 / 미해결. SCR-021 상담 배치 화면에 표시된다 | POL-042 |
| 5 | 마음 상태 | 입력(선택) | 자유 서술 최대 500자. 민감정보로 암호화 저장 | POL-041, POL-042 |
| 6 | 건강 상태 | 선택+입력 | 몸 상태(불편함/양호) 필수, 알러지(있음/없음) 필수, 건강 상세 선택 500자. 숙소 배정·식단 참고 | POL-011, POL-041, POL-042 |
| 7 | 숙소 사용 여부 | 선택(필수) | 숙소 사용 / 숙소 필요 없음. 필요 없음 선택 시 배정 대상에서 자동 제외되고 별도 명단으로 관리 | POL-017 |
| 8 | 숙소 특이사항 | 입력(선택) | **자유 서술 한 칸만.** 선택형 체크박스를 두지 않는다(모두 체크하는 문제를 막기 위함). 입력 시 SCR-018 미배정 명단의 「특이사항 있음」 필터에 노출 | POL-011 |
| 9 | 배정 기준 안내 | 정보 | 「거동이 불편하시면 1층 침대를 우선 배정합니다(필수 반영).」 / 「아는 분과 가까운 자리는 확약해 드리기 어렵습니다.」 | POL-011, POL-012 |
| 10 | 이전 / 다음 | 버튼 | 인원이 남아 있으면 다음 인원으로, 마지막이면 SCR-005로 | |

## 5. 상태별 화면

| 상태 | 조건 | 표시 내용 |
|---|---|---|
| 기본 | 진입 직후 | 1번째 인원 입력 화면. [8]은 [7]이 「숙소 사용」일 때만 표시 |
| 숙소 미사용 | [7] = 숙소 필요 없음 | [8] 숨김. 안내 「숙소를 사용하지 않으시면 자리 배정 대상에서 제외됩니다.」 (POL-017) |
| 인원 반복 중 | 동행자 있음 | [3]에 진행 인원 표시. 이전 인원 값은 유지된다 |
| 입력 오류 | 필수 미선택 | 해당 항목에 오류 문구, 진행 차단 |
| 로딩 | 임시 저장 중 | [10] 비활성 |
| 에러 | 임시 저장 실패 | 토스트 「저장하지 못했습니다. 다시 시도해 주세요.」 입력값 유지 |

빈 상태: 해당 없음.

## 6. 입력 유효성

| 필드 | 필수 | 형식/제한 | 실패 시 문구 | 관련 정책 |
|---|---|---|---|---|
| 구원 여부 | Y | 해결 / 재확인 / 미해결 | 「구원여부을(를) 선택해 주세요.」 | POL-042 |
| 마음 상태 | N | 최대 500자 | 「500자 이내로 입력해 주세요.」 | POL-042 |
| 몸 상태 | Y | 불편함 / 양호 | 「몸상태을(를) 선택해 주세요.」 | POL-042 |
| 알러지 | Y | 있음 / 없음 | 「알러지을(를) 선택해 주세요.」 | POL-042 |
| 건강 상세 | N | 최대 500자 | 「500자 이내로 입력해 주세요.」 | POL-042 |
| 숙소 사용 여부 | Y | 숙소 사용 / 숙소 필요 없음 | 「숙소사용여부을(를) 선택해 주세요.」 | POL-042 |
| 숙소 특이사항 | N | 최대 500자 | 「500자 이내로 입력해 주세요.」 | POL-042 |

## 7. 인터랙션 상세

- [7]에서 「숙소 필요 없음」 선택 → [8]과 [9]가 숨겨지고 제외 안내가 뜬다. 다시 「숙소 사용」으로 바꾸면 이전 입력값이 살아난다(값은 보존, POL-017 예외).
- [10] [다음] → 현재 인원 유효성 검사 → 통과 시 다음 인원으로 이동하고 [3]이 갱신된다 → 마지막 인원이면 SCR-005로.
- [3]의 인원 점프 버튼으로 이미 입력한 인원으로 돌아가면 값이 그대로 남아 있다.

## 8. 목업 동작 (HTML)

- 동행자 3명 시나리오로 **인원별 반복 입력이 실제로 동작한다.** 인원을 옮겨 다녀도 입력값이 각각 보존된다.
- [7]을 「숙소 필요 없음」으로 바꾸면 [8][9]가 실제로 숨겨지고 POL-017 안내가 뜬다.
- 필수 항목을 비우고 [다음]을 누르면 POL-042 검사가 걸린다.
