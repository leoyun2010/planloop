## 1. 화면 목적

상담은 **본부에서만 접수한다**는 점을 안내하고 접수처로 연결한다. 확정된 상담 일시·상담실만 조회하게 한다.

## 3. 컴포넌트 트리 (개발 인수인계용)

```jsx
<CounselInfoPage>
  <MobileHeader title="상담 받고 싶으시면" sub="상담 안내" />   {/* [1] */}
  <IntroText />                                                 {/* [2] */}

  <HowToApplyCard />                   {/* [3] 신청 폼을 두지 않는다 — 있으면 정책 위반 (POL-021) */}

  <DeskContactCard                     {/* [4] 접수처 번호·운영 시간 + 전화 걸기 */}
    tel={conf.deskTel} hours="08:00 ~ 21:00"
    onCall={() => location.href = `tel:${conf.deskTel}`} />

  <MyCounselCard                       {/* [5] 확정 건만 표시. 배치 전이면 대기 안내 */}
    session={mySession}
    emptyText="아직 접수된 상담이 없습니다." />

  <BackButton onClick={goBack} />      {/* [6] */}
</CounselInfoPage>
```

> **이 화면에는 상담 신청 입력 폼을 만들지 않는다.** 사용자 화면에 폼이 존재하면 POL-021 위반이다.

## 4. 구성 요소 정의

| # | 요소 | 유형 | 내용/동작 | 관련 정책 |
|---|---|---|---|---|
| 1 | 상단 헤더 | 공통 | 「상담 안내」 + 「상담 받고 싶으시면」 | |
| 2 | 안내 문구 | 정보 | 「말씀을 듣거나 신앙 생활 중 궁금한 점, 고민이 있으시면 상담을 받으실 수 있습니다.」 | |
| 3 | 신청 방법 | 정보 | 「상담은 본부 접수처에서 직접 신청하시거나 전화로 말씀해 주세요.」 신청 폼 없음 | POL-021 |
| 4 | 접수처 연락처 | 정보+버튼 | 본부 접수처 번호와 운영 시간(08:00~21:00). [전화 걸기]로 전화 앱 연결 | POL-021 |

## 5. 상태별 화면

| 상태 | 조건 | 표시 내용 |
|---|---|---|
| 기본 | 접수 이력 없음 | [5]에 「아직 접수된 상담이 없습니다. 상담을 원하시면 접수처로 연락해 주세요.」 |
| 배치 대기 | 본부 접수 완료, 미배치 | [5]에 「배치 대기」 배지 + 「본부에서 상담사님과 시간을 맞추고 있습니다.」 |
| 배치 확정 | 상담실·상담사·시간 확정 | [5]에 일시와 상담실 표시 |
| 상담 종료 | 상담 완료 | [5]에 「상담 종료」 배지. 결과는 사용자에게 노출하지 않는다 |
| 운영 시간 외 | 현재 시각이 08:00~21:00 밖 | [4] 전화 걸기 옆에 「지금은 접수처 운영 시간이 아닙니다.」 |
| 로딩 / 에러 | 조회 중 / 실패 | 스켈레톤 / 「상담 정보를 불러오지 못했습니다.」 |

빈 상태: [5]의 「아직 접수된 상담이 없습니다.」가 곧 빈 상태다.

## 6. 입력 유효성

**입력 폼 없음 — 의도적으로 두지 않는다** (POL-021). 신청자별 특이사항이 많아 실시간 대화로 정하기 위한 것이다.

## 7. 인터랙션 상세

- [4] [전화 걸기] → `tel:` 링크로 전화 앱 연결.
- 본부가 SCR-021에서 배치를 확정하면 [5]와 SCR-008 마이페이지에 동시에 반영된다.
- 상담 결과(해결/재상담/미해결)는 사용자에게 노출하지 않는다. 결과는 운영 집계·간증자 컨택 목적으로만 쓴다(POL-024).

## 8. 목업 동작 (HTML)

- [5]의 상태를 **없음 / 배치 대기 / 배치 확정 / 상담 종료** 4단계로 전환해 볼 수 있다.
- 운영 시간 외 상태를 켜면 [4]에 안내가 실제로 붙는다.
- 이 화면에 신청 폼이 없다는 것 자체가 POL-021 검증 포인트다.
