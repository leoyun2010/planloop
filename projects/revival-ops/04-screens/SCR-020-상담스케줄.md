## 1. 화면 목적

**정해진 일정이 실제로 어떻게 흘러가는지 보고 진행 상태를 바꾸는 현황판.** 지금 누가 누구와 상담 중인지, 몇 시에 무엇이 남았는지를 한 화면에서 본다.

## 3. 컴포넌트 트리 (개발 인수인계용)

```jsx
<AdminLayout active="schedule">
  <PageHeader title="상담 스케줄 (타임라인)">        {/* [1] */}
    <Button label="운영 시간 설정"  onClick={openHours} />   {/* POL-022 미확정 */}
    <Button label="상담실 설정"     onClick={openRooms} />   {/* POL-036 미확정 */}
  </PageHeader>

  <DateTabs dates={dates} value={date} onChange={setDate} /> {/* [2] 날짜별 관리 (POL-035) */}

  <Timeline                                          {/* [3] 상담사=열, 시간=세로축 */}
    counselors={counselors}
    range={hours}                                    /* 운영 시간대 설정값 (POL-022) */
    slotMinutes={30}                                 /* 격자 단위 30분 (POL-050) */
    blocks={blocks}
    renderBlock={b => (
      <Block status={b.status}                       /* 대기(초록)/진행 중(노랑)/종료(회색) */
        scheduled={b.scheduledFrom, b.scheduledTo}    /* [4] 예정선 */
        actual={b.actualFrom, b.actualTo}             /* [4] 실제 진행 블록 — 겹쳐 표시 */
        minHeight={28}                                /* 짧아도 상태 문구가 보이게 */
        onClick={openDrawer} />
    )}
    unavailable={availability}                       /* 상담사 가능 시간 밖은 음영 (POL-035) */
    onEmptyClick={openOnSiteAssign}                  /* [6] 빈 칸(30분 슬롯) 클릭 → 현장 배정 (POL-050) */
    onAddCounselor={openAddCounselor} />

  <Drawer open={!!sel}>                              {/* [5] 현장에서 그 자리에 처리 (POL-035) */}
    <StatusButtons value={sel.status}
      options={['대기','진행 중','상담 종료']}
      onChange={setStatus} />                        /* 누르면 블록 색·문구가 즉시 바뀐다 */
    <ScheduleVsActual />                             /* 지연 여부 표시 */
    <Select name="room" options={rooms} onChange={changeRoom} />   /* 변경 이력 기록 (POL-033) */
    <SegmentField name="result"    options={['해결','재상담 필요','미해결']} />   {/* POL-024 */}
    <SegmentField name="testimony" options={['가능','본인 거절','해당 없음']} />
    <TextArea name="memo" />
    <Button primary label="저장" onClick={save} />   /* SCR-019와 같은 데이터 (POL-036) */
  </Drawer>
</AdminLayout>
```

> **이 화면에 「상담실 × 시간」 예약 격자를 두지 않는다.** SCR-021의 배치판과 역할이 겹치기 때문이다(POL-036).

## 4. 구성 요소 정의

| # | 요소 | 유형 | 내용/동작 | 관련 정책 |
|---|---|---|---|---|
| 1 | 페이지 헤더 | 공통 | 「상담 스케줄 (타임라인)」 + [운영 시간 설정] [상담실 설정] | POL-022, POL-036 |
| 2 | 날짜 탭 | 탭 | 날짜별로 타임라인을 관리한다. 상담사 가능 시간이 날마다 다르기 때문 | POL-035 |
| 3 | 타임라인 격자 | 도면 | **상담사 = 열, 시간 = 세로축.** 세로축은 **30분 단위**로 쪼갠다(정시 경계는 실선, 30분 경계는 점선, 정시에만 라벨 표기). 상담사 가능 시간 밖은 음영 표시 | POL-035, POL-036, POL-050 |
| 4 | 예정선 + 진행 블록 | 도면 | 배정된 **예정 시간을 세로 선**으로, **실제 진행을 블록**으로 겹쳐 표시. 블록이 선보다 길면 지연, 짧으면 조기 종료. 상태별 색 — 대기(초록) / 진행 중(노랑) / 상담 종료(회색). 짧은 블록도 상태 문구가 보이도록 최소 높이 유지 | POL-035 |
| 5 | 관리 드로어 | 드로어 | 블록 클릭 시 오른쪽에 열림. 내담자·예정 시간·장소·결과를 한 화면에서 다룬다. **예정 시간은 30분 단위, 실제 진행 시간은 분 단위**로 보여준다. 진행 상태를 누르면 **타임라인 블록 색·문구가 즉시** 바뀐다 | POL-035, POL-024, POL-033, POL-050 |
| 6 | 빈 칸 현장 배정 | 클릭 | 상담사 열의 빈 **30분 슬롯**을 클릭하면 배치 대기자 중에서 골라 그 시간에 배정한다. 기본 길이는 30분. **SCR-021과 같은 데이터를 쓴다**(중복 배치 금지) | POL-036, POL-050 |
| — | 상담사 추가 | 버튼 | 이름·소속·연락처·담당 상담실을 입력해 열을 추가 | |

## 5. 상태별 화면

| 상태 | 조건 | 표시 내용 |
|---|---|---|
| 기본 | 상담사·배정 있음 | 타임라인 격자 |
| 상담사 없음 | 그 날짜에 상담사 0명 | 「이 날짜에 등록된 상담사가 없습니다.」 + [+ 상담사 추가] — 빈 격자를 두지 않는다 |
| 배정 없음 | 블록 0건 | 격자만 표시하고 「배정된 상담이 없습니다. 빈 칸을 클릭해 배치할 수 있습니다.」 |
| 지연 | 실제 종료 > 예정 종료 | 블록이 예정선보다 길게 그려지고 「지연」 표시 |
| 상태 역행 | 종료 → 대기 시도 | 차단. 「종료된 상담은 되돌릴 수 없습니다. 새로 배정해 주세요.」 |
| 단계 건너뜀 | 대기 → 상담 종료 | 경고(진행 가능). 「진행 중 단계를 거치지 않았습니다. 그대로 종료하시겠습니까?」 |
| 이중 배치 | 같은 상담사·같은 시간 | 차단. 「이 시간에 이미 배정된 상담이 있습니다.」 |
| 운영 시간 밖 | 범위 밖 배정 시도 | 차단. 「운영 시간대({시작}~{종료}) 안에서만 배정할 수 있습니다.」 |
| 시간 단위 위반 | 30분 단위가 아닌 시각 입력 | 차단. 「상담 시간은 30분 단위로만 설정할 수 있습니다. (예: 10:00, 10:30)」 |
| 길이 미달 | 30분보다 짧은 예정 시간 | 차단. 「상담은 30분 이상으로 설정해 주세요.」 |
| 종료 역전 | 종료 ≤ 시작 | 차단. 「종료 시각은 시작 시각보다 뒤여야 합니다.」 |
| 로딩 / 에러 | 조회 중 / 실패 | 스켈레톤 / 「타임라인을 불러오지 못했습니다.」 |

| 필드 | 필수 | 형식/제한 | 실패 시 문구 | 관련 정책 |
|---|---|---|---|---|
| 진행 상태 | Y | 대기 / 진행 중 / 상담 종료 / 취소 | 역행: 「종료된 상담은 되돌릴 수 없습니다. 새로 배정해 주세요.」 | POL-035 |
| 예정 시작 시각 | Y | **30분 단위**(매시 00분·30분) | 「상담 시간은 30분 단위로만 설정할 수 있습니다. (예: 10:00, 10:30)」 | POL-050 |
| 예정 종료 시각 | Y | **30분 단위**, 시작보다 뒤, 최소 30분 | 「종료 시각은 시작 시각보다 뒤여야 합니다.」 / 「상담은 30분 이상으로 설정해 주세요.」 | POL-050 |

| 간증 가능 여부 | N(종료 시 Y) | 가능 / 본인 거절 / 해당 없음 | 「간증 가능 여부를 선택해 주세요.」 | POL-024 |
| 메모 | N | 최대 500자 | 「500자 이내로 입력해 주세요.」 | POL-042 |

## 7. 인터랙션 상세

- 블록 클릭 → 드로어 → [진행 중] → **왼쪽 블록 색과 문구가 그 자리에서 바뀐다.** 화면 이동 없음(POL-035).
- 드로어에서 입력한 결과·간증 여부는 SCR-019 현황판의 집계와 간증자 명단에 그대로 반영된다(POL-036).
- 저장 전에 드로어를 닫으면 「저장하지 않은 내용이 있습니다. 닫으시겠습니까?」로 확인한다.
- 상담 장소를 바꾸면 변경 이력에 기록된다(POL-033).
- **예정 시간은 30분 단위로만 잡는다**(POL-050). 타임라인 격자도 30분으로 쪼개져 있어 빈 칸 하나가 곧 30분 슬롯이고, 클릭하면 그 슬롯에 30분짜리 상담이 배정된다.
- **실제 진행 시간에는 30분 제한을 적용하지 않는다**(POL-050 예외). 10:00~10:30 예정 상담이 10:05에 시작해 10:42에 끝나면 그대로 기록하고, 예정선보다 긴 블록으로 그려 지연을 보여준다(POL-035).

> **POL-022(운영 시간대)와 상담실 개수는 미확정이다**(오픈 이슈 OI-13). 현재 목업은 09:00~24:00, 상담실 7개를 가정한다.
> **시간 단위는 30분으로 확정되었다**(POL-050, 2026-09-04 회의 결정 D-3). 이전 목업의 40분 단위 예시는 모두 30분으로 교체했다.
> **POL-035의 상담사 가능 시간 입력 위치도 미확정이다**(오픈 이슈 OI-7). 상담사 등록 팝업에서 받을지, 타임라인에 음영 레이어로 표시할지 정해야 한다. 목업은 음영 레이어 방식으로 그렸다.

## 8. 목업 동작 (HTML)

- **날짜 탭 3개가 실제로 전환되고** 날짜별 블록이 다르게 나온다.
- 블록을 클릭하면 **오른쪽 드로어가 실제로 열리고**, 진행 상태를 바꾸면 **블록 색과 문구가 즉시 바뀐다**(POL-035).
- **예정선과 실제 진행이 겹쳐 그려지고**, 지연이면 「지연」 배지가 붙는다.
- 종료된 상담을 대기로 되돌리려 하면 **실제로 차단**된다. 대기 → 종료로 건너뛰면 경고가 뜬다.
- **타임라인 격자가 30분으로 그려진다**(POL-050). 정시 경계는 실선, 30분 경계는 점선이고 라벨은 정시에만 붙는다.
- **빈 칸(30분 슬롯)을 클릭하면 배치 대기자 목록이 열려 현장 배정**이 실제로 된다. 배정 길이는 30분이고, 슬롯이 기존 예정 구간과 겹치면 이중 배치로 차단된다(POL-036, POL-050).
- [운영 시간 설정]에서 범위를 줄이면, 이미 배정된 시간을 벗어날 경우 **실제로 차단**된다(POL-022). **30분 단위가 아닌 값(예: 9.2)을 넣으면 차단**된다(POL-050).
- 상담사 가능 시간 밖은 음영으로 표시되고 그 자리에는 배정할 수 없다.
