## 1. 화면 목적

인도자가 함께 오는 인원을 같은 신청서에 등록하고, 총 인원과 청구 금액을 확인하게 한다.

## 3. 컴포넌트 트리 (개발 인수인계용)

## 4. 구성 요소 정의

| # | 요소 | 유형 | 내용/동작 | 관련 정책 |
|---|---|---|---|---|
| 1 | 상단 헤더 | 공통 | 「집회 신청 · 2/4」 + 「함께 오시는 분」 | |
| 2 | 단계 진행 바 | 정보 | 2/4단계, 진행률 50% | |
| 3 | 동행자 목록 | 목록 | 인도자 본인을 최상단에 고정 표시(삭제·순번 변경 불가). 동행자는 순번과 함께 나열, 각각 [수정] [삭제] | |
| 4 | 사람 추가 버튼 | 버튼 | 모달 열기. 입력 항목은 SCR-002 기본 정보와 동일. 상한 초과 시 차단 | POL-042, POL-043 |
| 5 | 총 인원·금액 | 정보 | 「총 {n}명」으로 실제 인원 표기(「본인 포함 3명」 같은 고정 문구 금지). 청구 금액 = 총 인원 × 참가비(80,000원) | |
| 6 | 대표 연락처 안내 | 정보 | 「입금 안내와 각종 안내는 인도자(대표자) 연락처로 발송됩니다.」 | POL-006 |
| 7 | 이전 / 다음 | 버튼 | 이전 → SCR-002(입력값 유지), 다음 → SCR-004 | |

## 5. 상태별 화면

| 상태 | 조건 | 표시 내용 |
|---|---|---|
| 기본 | 진입 직후 | [3]에 인도자 본인 1명만. [5] 「총 1명 · 80,000원」 |
| 동행자 있음 | 1명 이상 추가 | 목록에 순번과 함께 표시. [5] 실시간 재계산 |
| 빈 상태 | 동행자 0명 | 목록에 안내 「아직 추가한 분이 없습니다. 혼자 오시면 그대로 다음으로 넘어가세요.」 |
| 상한 도달 | 총 인원 = 설정 상한 | [4] 비활성 + 「한 번에 신청할 수 있는 인원은 최대 {상한}명입니다. 인원이 더 많으시면 나누어 신청해 주세요.」 |
| 로딩 | 저장 중 | [7] 다음 버튼 비활성 + 스피너 |
| 에러 | 저장 실패 | 토스트 「저장하지 못했습니다. 다시 시도해 주세요.」 입력값 유지 |

## 6. 입력 유효성 (동행자 추가 모달)

| 필드 | 필수 | 형식/제한 | 실패 시 문구 | 관련 정책 |
|---|---|---|---|---|
| 이름 | Y | 2~20자 | 「이름은 2자 이상 20자 이하로 입력해 주세요.」 | POL-042 |
| 휴대폰 번호 | Y | 숫자 10~11자리 | 「휴대폰 번호는 숫자 10~11자리로 입력해 주세요.」 | POL-042 |
| 지역 | Y | 1~20자 | 「지역을 입력해 주세요.」 | POL-042 |
| 성별 | Y | 남 / 여 | 「성별을(를) 선택해 주세요.」 | POL-042 |
| (인원 상한) | - | 총 인원 ≤ 설정값 | 「한 번에 신청할 수 있는 인원은 최대 {상한}명입니다. 인원이 더 많으시면 나누어 신청해 주세요.」 | POL-043 |

> **POL-043은 미확정이다.** 인원 상한 기본값이 정해지지 않았다(오픈 이슈 OI-10). 목업은 확인용으로 6명을 임시 상한으로 둔다. 값이 확정되면 이 문서와 목업을 함께 고친다.

## 7. 인터랙션 상세

- [4] → 모달 → [추가] → 유효성 통과 시 목록에 순번과 함께 추가되고 모달이 닫힌다 → [5] 즉시 재계산.
- [3]의 [삭제] → 확인 없이 즉시 삭제하고 [5] 재계산. 인도자 본인 행에는 [삭제]가 없다.
- [3]의 [수정] → 같은 모달을 값이 채워진 상태로 연다.
- 총 인원이 상한에 도달하면 [4]가 비활성으로 바뀌고 사유 문구가 노출된다.

## 8. 목업 동작 (HTML)

- 동행자 추가·수정·삭제가 실제로 동작하고, 총 인원과 청구 금액이 즉시 재계산된다.
- 모달 입력에 POL-042 검증이 실제로 걸린다.
- 총 6명(임시 상한)에 도달하면 [＋ 사람 추가]가 실제로 비활성화되고 POL-043 문구가 뜬다.
