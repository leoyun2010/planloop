## 1. 화면 목적

정기편은 신청 없이 이용할 수 있음을 안내하고, 중간 이동이 필요한 사람에게 수시 셔틀을 요청받은 뒤 확정 배차를 보여준다.

## 4. 구성 요소 정의

| # | 요소 | 유형 | 내용/동작 | 관련 정책 |
|---|---|---|---|---|
| 1 | 상단 헤더 | 공통 | 「셔틀」 + 「타는 곳 · 시간」 | |
| 2 | 정기 운행 | 목록 | 관리자가 등록한 정기편 시간표. 「신청 없이 이용하실 수 있습니다」 함께 안내 | |
| 3 | 확정 배차 | 정보 | 배차 확정 시 확정 시간·방향·차량(인승·번호)·운전자 표시. [탑승 확정하기] 버튼 | POL-027, POL-049 |
| 4 | 셔틀 요청 | 버튼 | 요청 모달 열기 | |
| 5 | 하단 탭바 | 공통 | 셔틀 탭 활성 | |
| 6 | 구분 | 선택(필수) | 참여자 / 스태프. 스태프도 요청할 수 있다 | POL-028 |
| 7 | 방향 | 선택(필수) | 나가는 편(집회장→외부) / 들어오는 편(외부→집회장) | POL-025 |
| 8 | 목적지 | 입력(필수) | 1~30자 | POL-042 |
| 9 | 출발 희망 시간 | 입력(필수) | 현재 시각 이후만 | |
| 10 | 동승 인원 | 입력(필수) | 1 이상 정수 | |
| 11 | 연락처 | 입력(필수) | 숫자 10~11자리 | POL-042 |

## 5. 상태별 화면

| 상태 | 조건 | 표시 내용 |
|---|---|---|
| 기본 (요청 없음) | 내 요청 없음 | [3] 자리에 「신청하신 셔틀이 없습니다. 필요하시면 아래에서 요청해 주세요.」 |
| 배차 대기 | 요청했으나 미배차 | [3]에 「대기」 배지 + 「본부에서 배차를 확정하면 여기에 시간과 차량이 표시됩니다.」 |
| 배차 확정 | 배차 확정됨 | [3]에 「배차 확정」 + 차량·운전자 + [탑승 확정하기] |
| 탑승 확정 완료 | 참가자가 확정 누름 | 버튼이 「탑승 확정됨」으로 바뀌고 비활성 |
| 탑승 확정 마감 | 출발 10분 전 경과 | 버튼 비활성 + 「탑승 확정은 출발 10분 전까지만 가능합니다. 셔틀 담당자에게 직접 말씀해 주세요.」 (POL-049) |
| 배차 취소 | 본부가 배차 취소 | 확정 정보가 사라지고 「배차가 취소되었습니다.」 표시. 탑승 확정도 해제 (POL-049) |
| 빈 상태 (정기편) | 등록된 정기편 0건 | 「등록된 정기 운행이 없습니다.」 |
| 로딩 / 에러 | 조회 중 / 실패 | 스켈레톤 / 「셔틀 정보를 불러오지 못했습니다.」 + [다시 시도] |

## 6. 입력 유효성 (요청 모달)

| 필드 | 필수 | 형식/제한 | 실패 시 문구 | 관련 정책 |
|---|---|---|---|---|
| 구분 | Y | 참여자 / 스태프 | 「구분(참여자 / 스태프)을 선택해 주세요.」 | POL-028 |
| 방향 | Y | 나가는 편 / 들어오는 편 | 「가는 방향을 선택해 주세요.」 | POL-025 |
| 목적지 | Y | 1~30자 | 「목적지를 입력해 주세요.」 | POL-042 |
| 출발 희망 시간 | Y | 현재 시각 이후 | 「출발 희망 시간은 지금 이후로 정해 주세요.」 | |
| 동승 인원 | Y | 1 이상 정수 | 「동승 인원을 1명 이상으로 입력해 주세요.」 | |
| 연락처 | Y | 숫자 10~11자리 | 「휴대폰 번호는 숫자 10~11자리로 입력해 주세요.」 | POL-042 |

## 7. 인터랙션 상세

- [4] → 모달 → [요청하기] → 검증 통과 시 [3]이 「대기」 상태로 바뀌고, 관리자 SCR-022의 해당 방향 대기 목록에 즉시 노출된다.
- 본부가 배차를 확정하면 [3]에 시간·차량·운전자가 채워지고 [탑승 확정하기]가 활성화된다.
- [탑승 확정하기]는 출발 10분 전까지만 눌린다. 이후 자동 비활성 + 안내(POL-049).
- 배차가 취소되면 확정 정보와 탑승 확정이 함께 해제된다.

## 8. 목업 동작 (HTML)

- 요청 모달의 6개 필드 검증이 실제로 동작하고, 요청하면 [3]이 「대기」로 실제 전이된다.
- [본부가 배차 확정] 버튼으로 대기 → 확정 전이를 확인할 수 있고, 차량 정보가 채워진다.
- **탑승 확정 마감(POL-049)이 실제로 동작한다.** 출발 시각을 5분 뒤로 당기면 버튼이 비활성화되고 문구가 뜬다.
- [배차 취소] 시 확정과 탑승 확정이 함께 해제된다.
