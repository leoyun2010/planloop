## 1. 화면 목적

배치도를 만들고 정해진 룰대로 자리를 배정한다. **현장에서 불만이 들어왔을 때 바꿀 자리가 즉시 보이고 3클릭 안에 옮길 수 있어야 한다.**

## 4. 구성 요소 정의

| # | 요소 | 유형 | 내용/동작 | 관련 정책 |
|---|---|---|---|---|
| 1 | 좌석 카운터 | 지표 | 총 좌석·배정·보류·빈자리를 제목 옆에 **상시 표시.** 좌석 상태가 바뀔 때마다 즉시 갱신. **배정+보류+빈자리 = 총 좌석**이 항상 성립해야 한다 | POL-048 |
| 1 | 배정 룰 버튼 | 버튼 | ⓘ 팝업으로 배정 룰·시점을 연다. 화면에 상시 노출하지 않는다 | POL-010~017 |
| 2 | 배치도 만들기 | 입력 | 구역명·방 개수·방당 1층 침대 수·방당 2층 침대 수 → 좌석 자동 생성, 즉시 렌더. [초기화] [고정 구역 재사용] | POL-015, POL-048 |
| 3 | 미배정 명단 | 목록 | 특이사항 있음 / 동행 그룹 / 일반 / 숙소 미사용 필터. 각 행에 [1층 우선 배정] 또는 [그룹 같은 방] 버튼. **숙소 미사용자는 배정 대상 목록에 나오지 않는다** | POL-011, POL-010, POL-017 |
| 4 | 배치도 | 도면 | 구역 → 방 → 1층/2층 좌석. 좌석 상태 4종 — 빈 자리 / 우선 배정 / 일반 배정 / 보류. 좌석 클릭 시 상세 모달 | POL-011, POL-013, POL-018 |
| — | 빈자리만 보기 | 토글 | 빈 자리만 강조. 불만 대응 시 바꿀 자리를 즉시 찾기 위한 것 | POL-018 |
| — | 보류 좌석 지정 | 버튼 | 방마다 1층 한 자리를 보류로 확보. 일괄 배치에서 자동 제외 | POL-013 |
| — | 일괄 랜덤 배치 | 버튼 | 남은 인원을 **2층부터 채워** 일괄 배정. 보류·기배정 좌석은 건드리지 않는다. 방별로 고르게 | POL-012, POL-013, POL-014 |
| — | 좌석 상세 모달 | 모달 | 배정·이동·교환·해제·보류 지정·메모를 **한 화면에서** 처리. 모든 변경은 이력 기록 | POL-018, POL-033 |

## 5. 상태별 화면

| 상태 | 조건 | 표시 내용 |
|---|---|---|
| 배치도 없음 | 좌석 0개 | 「아직 배치도가 없습니다. 위에서 구역과 방을 입력해 만들어 주세요.」 |
| 기본 | 배치도 있음 | 좌석 도면 + 미배정 명단 |
| 미배정 없음 | 전원 배정 | 「배정할 인원이 없습니다.」 |
| 좌석 부족 | 미배정 인원 > 빈 자리 | 일괄 배치 차단. 「남은 자리보다 배정할 인원이 {n}명 많습니다. 좌석을 더 만들어 주세요.」 |
| 1층 없음 | 1층 빈 자리 0 | 우선 배정 차단. 「1층에 남은 자리가 없습니다. 보류 좌석을 해제하거나 배정된 자리를 조정해 주세요.」 |
| 합계 불일치 | 배정+보류+빈자리 ≠ 총 | 경고 표시 + 일괄 배치 차단. 「좌석 수가 맞지 않습니다. 총 {총}석인데 배정 {n} + 보류 {n} + 빈자리 {n} = {합}석입니다.」 | 
| 보류 미지정 | 보류 좌석 없는 방 존재 | 일괄 배치 전 경고. 「보류 좌석이 지정되지 않은 방이 {n}개 있습니다. 현장 대응 자리가 부족할 수 있습니다.」 |
| 시점 이름 | 집회 3일 전 이전 | 일괄 배치 시 경고. 「아직 접수가 진행 중입니다. 지금 배치하면 이후 신청자를 다시 배정해야 합니다.」 |
| 로딩 / 에러 | 조회 중 / 실패 | 스켈레톤 / 「배치도를 불러오지 못했습니다.」 |

## 7. 인터랙션 상세

- **3클릭 이내 좌석 이동**(POL-018): [빈자리만 보기] → 좌석 클릭 → [다른 자리로 이동] 선택. 이 흐름을 넘기면 정책 위반이다.
- 이미 배정된 좌석으로 이동을 시도하면 「이 자리에는 {이름} 님이 배정되어 있습니다. 두 분의 자리를 서로 바꾸시겠습니까?」로 교환 여부를 묻는다.
- 거동 불편 여부는 **담당자가 특이사항 서술을 읽고 판단**한다. 시스템이 자동 판정하지 않는다(POL-011 예외).
- 성별이 다른 동행 구성원은 같은 방에 배정되지 않는다. 분리된 인원을 화면에 표시한다(POL-010).
- 모든 좌석 변경은 담당자와 함께 이력에 기록된다(POL-033).

## 8. 목업 동작 (HTML)

- **배치도 생성이 실제로 동작한다.** 구역·방·침대 수를 넣으면 좌석이 즉시 그려지고 카운터가 갱신된다.
- **POL-048 합계 검사가 실시간으로 돈다.** 배정·보류·해제할 때마다 「배정+보류+빈자리 = 총 좌석」을 검사하고, 어긋나면 경고가 뜨고 일괄 배치가 차단된다.
- [1층 우선 배정]은 1층 빈 자리가 없으면 실제로 차단된다(POL-011).
- [그룹 같은 방]은 성별이 다른 인원을 실제로 분리 배정하고 알려준다(POL-010).
- [보류 좌석 지정]은 방마다 1층 한 자리를 실제로 보류로 만들고, **일괄 배치에서 제외된다**(POL-013).
- [일괄 랜덤 배치]는 **2층부터 채우고** 보류·기배정을 건드리지 않으며, 좌석이 부족하면 차단된다(POL-012·013).
- 좌석 클릭 → 이동·교환·해제·보류·메모가 모두 동작하고, 각 처리가 이력에 쌓인다.
- 숙소 미사용자는 미배정 명단의 배정 대상에 나오지 않고 별도 탭에서만 보인다(POL-017).
