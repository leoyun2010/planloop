## 1. 화면 목적

참가비·계좌, 성경책 구매, 숙소 위치, 자주 묻는 질문을 **문자 앱을 찾지 않고 언제든 다시 볼 수 있게** 한다.

## 5. 상태별 화면

| 상태 | 조건 | 표시 내용 |
|---|---|---|
| 기본 | 표시 항목 1개 이상 | 아코디언 목록. 첫 항목 펼침 |
| 빈 상태 | 표시 항목 0건 | 「아직 등록된 안내문이 없습니다.」 — 빈 화면을 두지 않는다 (POL-046) |
| 접수 마감 후 | 마감 이후 | 정상 동작한다. 마감은 신규 신청만 차단한다 |
| 로딩 / 에러 | 조회 중 / 실패 | 스켈레톤 / 「안내문을 불러오지 못했습니다.」 + [다시 시도] |

## 6. 입력 유효성

입력 폼 없음 — 해당 없음. 사용자는 열람만 가능하다(POL-046).

## 7. 인터랙션 상세

- 항목을 누르면 펼치고, 다시 누르면 접는다. 여러 항목을 동시에 펼칠 수 있다.
- 관리자가 SCR-023에서 항목을 비표시로 바꾸면 이 화면에서 즉시 사라진다.
- **참가비·계좌 항목은 집회 설정값과 일치해야 한다.** 어긋나면 관리자 화면에 경고가 뜬다(POL-046). 사용자 화면에는 경고를 노출하지 않는다.

## 8. 목업 동작 (HTML)

- 아코디언 4개가 실제로 펼쳐지고 접힌다.
- [항목 전부 비표시로] 버튼으로 POL-046의 노출 필터와 빈 상태 문구를 확인할 수 있다.
- [계좌 불일치 만들기]로 관리자 쪽 경고 조건(POL-046)이 무엇인지 확인할 수 있다.
