## 1. 화면 목적

셔틀 요청을 **출발 시간순으로** 보고, 태워 갈 사람만 체크해 바로 배차한다. 사람 이름보다 출발 시간이 핵심이다.

## 3. 컴포넌트 트리 (개발 인수인계용)

```jsx
<AdminLayout active="shuttle" role={account.role}>   {/* 셔틀팀도 접근 (POL-027, POL-031) */}
  <PageHeader title="셔틀 관리"                       {/* [1] */}
    summary={`대기 ${waiting.length} · 확정 ${dispatched.length}`}>
    <Button primary label="+ 전화 요청 등록" onClick={openPhoneReq} />   {/* POL-027 */}
  </PageHeader>

  <Toolbar>
    <TabBar data-tabs="dir"                          {/* [2] 방향 분리 (POL-025) */}
      items={[`나가는 편(OUT)`, `들어오는 편(IN)`]} />
    <Button label="정기편 관리" onClick={openRegular} />               {/* REQ-060 */}
  </Toolbar>

  <RequestTable rows={sortByDepart(rows)}>           {/* [3] 출발 시간 오름차순 (POL-026) */}
    <Col name="check" type="checkbox" />
    <Col name="departAt" first big />                {/* 가장 왼쪽·가장 크게 (POL-026) */}
    <Col name="name" />
    <Col name="riderType" render={r => r.riderType === '스태프'
      ? <Chip label="스태프" /> : '참여자'} />        {/* POL-028 구분 배지 */}
    <Col name="destination" /><Col name="companions" /><Col name="phone" />
    <Col name="status" render={r => <Chip label={r.status} />} />
  </RequestTable>

  <DispatchBar count={selected.length}                {/* [4] 나눠 배차 가능 (POL-026) */}
    seats={sumCompanions(selected)}>
    <Select name="vehicleType" options={['12인승','25인승','45인승']} />
    <TextField name="vehicleNo" required />           {/* POL-027 */}
    <TextField name="driver" required />              {/* POL-027 */}
    <Button primary label="선택 배차 확정" onClick={dispatch} />
  </DispatchBar>

  <DispatchList rows={dispatched}>                    {/* [5] */}
    <Col name="departAt" /><Col name="route" /><Col name="vehicle" /><Col name="driver" />
    <Col name="boarded" render={d => `${d.boarded}/${d.total}`} />
    <Col name="actions" render={d => [
      <Button label="상세" onClick={openDetail(d)} />,   /* 탑승 확인 체크 */
      <Button label="취소" onClick={cancelDispatch(d)} />, /* 사유 필수 (POL-033) */
    ]} />
  </DispatchList>
</AdminLayout>
```

## 7. 인터랙션 상세

- 비슷한 시간대라도 인원이 차량 정원을 넘으면 **나눠 배차**한다. 체크박스로 태울 사람만 고른다(POL-026).
- 배차 확정 → 신청자의 SCR-010 셔틀 화면과 SCR-008 마이페이지에 확정 시간·차량이 표시된다.
- 배차 취소 → 사유 입력 필수. 사용자 쪽 확정 정보와 **탑승 확정이 함께 해제**된다(POL-049).
- 스태프 요청은 참가자 명단에 없어도 등록할 수 있다(POL-028 예외).
- 본부가 전화 요청을 대신 입력해도 **셔틀팀이 자기 계정으로 탑승자 명단을 보고 직접 배차**할 수 있다(POL-027).

## 8. 목업 동작 (HTML)

- **방향 탭이 실제로 분리**되어 있고 한 목록에 섞이지 않는다(POL-025 검증 포인트).
- **출발 시간 오름차순 정렬이 실제로 유지**되고 첫 열에 가장 크게 표시된다(POL-026).
- 체크박스로 여러 건을 골라 **선택 배차 확정**하면 요청이 대기 목록에서 빠지고 배차 현황에 들어간다.
- 차량번호·운전자를 비우고 확정하면 **실제로 차단**된다(POL-027).
- 선택 인원이 차량 인승을 넘으면 경고가 뜬다 — 나눠 배차하라는 안내.
- [상세]에서 **탑승 확인 체크**가 동작하고 탑승 인원이 실시간으로 갱신된다.
- [취소]는 사유 없이 진행되지 않고, 취소하면 「사용자 탑승 확정도 함께 해제」 안내가 뜬다(POL-049).
- **[셔틀팀 계정으로 보기]** 버튼으로 사이드 내비에 셔틀 관리만 남는 것을 확인할 수 있다(POL-031, POL-032).
