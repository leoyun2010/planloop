## 1. 화면 목적

개인정보 수집·이용 동의와 민감정보 수집·이용 동의를 **각각 별도로** 받고, 둘 다 동의해야 신청을 완료시킨다.

## 5. 상태별 화면

| 상태 | 조건 | 표시 내용 |
|---|---|---|
| 기본 | 진입 직후 | 두 체크 모두 해제. [7] 제출 버튼 비활성 |
| 일부 동의 | 하나만 체크 | [7] 비활성 유지 + [6] 강조 |
| 전체 동의 | 둘 다 체크 | [7] 활성 |
| 제출 중 | 서버 처리 중 | [7] 비활성 + 「신청을 저장하는 중입니다…」 (중복 제출 방지) |
| 정원 초과 | 제출 시 잔여 좌석 부족 | 차단. 「신청 인원이 남은 자리보다 많습니다. 남은 자리는 {잔여}명입니다. 본부 접수처(연락처)로 문의해 주세요.」 (POL-002) |
| 접수 마감 | 제출 시 마감 경과 | 차단. 「접수 기간이 종료되어 신청을 완료할 수 없습니다. 본부 접수처(연락처)로 문의해 주세요.」 (POL-001) |
| 에러 | 저장 실패 | 「저장하지 못했습니다. 다시 시도해 주세요.」 동의 체크 상태 유지 |
| 처리방침 미확정 | 처리방침 본문 없음 | [5]에 「개인정보 처리방침은 준비 중입니다.」 (오픈 이슈 OI-6) |

빈 상태: 해당 없음.

## 6. 입력 유효성

| 필드 | 필수 | 형식/제한 | 실패 시 문구 | 관련 정책 |
|---|---|---|---|---|
| 개인정보 동의 | Y | 체크 | 「신청을 완료하려면 개인정보 수집·이용 동의와 민감정보 수집·이용 동의가 모두 필요합니다.」 | POL-045 |
| 민감정보 동의 | Y | 체크 | 위와 같음 | POL-045 |

동의 일시 기록에 실패하면 신청을 완료하지 않는다 — 「동의 기록에 실패해 신청을 저장하지 못했습니다. 다시 시도해 주세요.」 (POL-045)

## 7. 인터랙션 상세

- 체크 상태가 바뀔 때마다 [7] 활성/비활성이 즉시 갱신된다.
- [7] 클릭 → 두 동의 확인 → 동의 일시 기록 → 접수 가능 여부 재검사(POL-001, POL-002) → SCR-006 이동.
- 두 동의를 한 체크박스로 합치지 않는다. 「모두 동의」 일괄 체크 버튼도 두지 않는다(민감정보 동의를 분리해 받는 것이 목적이기 때문).

## 8. 목업 동작 (HTML)

- 두 체크박스 상태에 따라 [7] 버튼이 실제로 활성/비활성으로 바뀐다.
- 하나만 체크하고 제출하면 POL-045 문구가 실제로 뜬다.
- 제출 시 **동의 일시가 실제로 기록되어** 화면에 표시된다.
- [5] 처리방침 링크는 미확정 상태(OI-6)를 그대로 보여준다.
