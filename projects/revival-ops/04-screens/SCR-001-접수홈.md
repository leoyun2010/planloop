## 1. 화면 목적

처음 온 참가자는 신청을 시작하고, 이미 신청한 참가자는 자기 신청 내역으로 갈 수 있게 한다. 접수 기간과 마감 조건을 첫 화면에서 알린다.

## 3. 컴포넌트 트리 (개발 인수인계용)

```jsx
<ApplyHomePage>
  <MobileHeader                      {/* [1] 공통 — 집회명 + 인사 */}
    conferenceName={conf.name} />

  <ApplyPeriodBanner                 {/* [2] 설정값 그대로 표시 (POL-001) */}
    startAt={conf.applyStartAt}
    endAt={conf.applyEndAt}
    showNoOnsite={conf.showNoOnsiteNotice}  /* [2] POL-003 문구 동시 노출 */
  />

  <EntrySegment                      {/* [3] 신규/재방문 토글 — 화면 구성이 바뀐다 */}
    value={mode} onChange={setMode} />

  {mode === 'new' && (
    <>
      <ApplyCTA                      {/* [4] 비활성 조건: 마감(POL-001) 또는 정원 도달(POL-002·044) */}
        disabled={!conf.applyOpen}
        disabledText={conf.blockReason}   /* 마감 문구 / 정원 마감 문구 */
        onClick={goto("SCR-002")} />
      <QuickLinks                    {/* [5] 4개 고정 — 마감 이후에도 동작한다 */}
        items={[
          { label: '공지 · 오늘 일정', to: 'SCR-009' },
          { label: '셔틀 시간 보기',   to: 'SCR-010' },
          { label: '상담 안내',        to: 'SCR-011' },
          { label: '안내문 다시 보기', to: 'SCR-012' },
        ]} />
    </>
  )}

  {mode === 'returning' && (
    <MyApplicationCard               {/* [6] 본인 확인 화면으로 */}
      onClick={goto("SCR-007")} />
  )}

  <BottomTabBar active="home" />     {/* [7] 공통 — 마감과 무관하게 항상 동작 */}
</ApplyHomePage>
```

## 4. 구성 요소 정의

| # | 요소 | 유형 | 내용/동작 | 관련 정책 |
|---|---|---|---|---|
| 1 | 상단 헤더 | 공통 | 집회명(작게) + 「반갑습니다」(크게) | |
| 2 | 접수 기간 배너 | 정보 | 집회 설정의 접수 시작·마감 일시를 그대로 표시. 「집회 시작 3일 전에 접수가 마감됩니다. 현장 접수는 받지 않으니 기간 내에 꼭 신청해 주세요.」를 함께 노출 | POL-001, POL-003 |
| 3 | 진입 분기 토글 | 토글 | 「신청하기」 / 「이미 신청했어요」. 선택에 따라 [4][5] 또는 [6]을 표시 | |
| 4 | 집회 신청 CTA | 버튼 | 클릭 시 SCR-002 이동. 마감 시 비활성 + 「온라인 접수가 마감되었습니다. (마감: {마감일시})」. 정원 도달 시 비활성 + 「접수 인원이 모두 찼습니다. 본부 접수처(연락처)로 문의해 주세요.」 | POL-001, POL-002, POL-044 |
| 5 | 자주 찾는 정보 | 목록 | 4개 바로가기 — SCR-009 / SCR-010 / SCR-011 / SCR-012. 접수 마감 이후에도 동작 | |
| 6 | 내 신청 확인 카드 | 버튼 | 클릭 시 SCR-007 이동. 「휴대폰 번호 + 이름으로 조회」 | POL-029 |
| 7 | 하단 탭바 | 공통 | 접수 · 공지/일정 · 셔틀 · 마이페이지. 현재 탭 강조 | |

## 5. 상태별 화면

| 상태 | 조건 | 표시 내용 |
|---|---|---|
| 기본 (접수 중) | 현재 시각이 접수 기간 내이고 잔여 좌석 있음 | [4] 활성. 배너에 접수 기간 표시 |
| 접수 전 | 현재 시각 < 접수 시작 일시 | [4] 비활성 + 「접수는 {시작일시}부터 시작합니다.」 |
| 접수 마감 | 현재 시각 > 접수 마감 일시 | [4] 비활성 + 「온라인 접수가 마감되었습니다. (마감: {마감일시})」. [5][7]은 정상 동작 |
| 정원 마감 | 온라인 접수 인원 ≥ 총 정원 − 버퍼 | [4] 비활성 + 「접수 인원이 모두 찼습니다. 본부 접수처(연락처)로 문의해 주세요.」 취소가 생겨도 자동으로 다시 열리지 않는다 (POL-044) |
| 로딩 | 집회 설정 조회 중 | 배너·CTA 자리에 스켈레톤 |
| 에러 | 집회 설정 조회 실패 | 「집회 정보를 불러오지 못했습니다.」 + [다시 시도] 버튼 |

빈 상태: 해당 없음 (목록형 화면이 아니다).

## 6. 입력 유효성

입력 폼 없음 — 해당 없음.

## 7. 인터랙션 상세

- **토글 전환**: [3]에서 「이미 신청했어요」 선택 → [4][5] 숨김, [6] 표시. 다시 「신청하기」 선택 → 원복. 페이지 이동 없음.
- **신청 시작**: [4] 클릭 → 접수 가능 여부를 서버에서 다시 확인(POL-001, POL-002) → 통과 시 SCR-002 이동, 실패 시 그 자리에서 사유 문구 표시.
- **마감 이후 URL 직접 접근**: `/apply/1` 로 직접 들어와도 제출이 완료되지 않는다(POL-001). 이 화면으로 돌려보낸다.

## 8. 목업 동작 (HTML)

- 상단 「접수 상태」 전환 버튼으로 **접수 중 / 접수 전 / 접수 마감 / 정원 마감** 4개 상태를 실제로 전환한다. CTA 활성·비활성과 안내 문구가 정책대로 바뀐다.
- 신규/재방문 토글이 실제로 화면 구성을 바꾼다.
