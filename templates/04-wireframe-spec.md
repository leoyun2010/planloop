## 1. 화면 목적

- 이 화면에서 사용자가 달성해야 하는 것 한 문장

## 2. 레이아웃 (텍스트 와이어프레임)

```
+--------------------------------------------------+
| [1] GNB: 로고 | 메뉴A | 메뉴B         [로그인]  |
+--------------------------------------------------+
| [2] 페이지 제목                                  |
|                                                  |
| [3] +------------------+  [4] +---------------+  |
|     | 콘텐츠 영역      |      | 사이드 영역   |  |
|     |                  |      |               |  |
|     +------------------+      +---------------+  |
|                                                  |
| [5] [ 주요 버튼 ]                                |
+--------------------------------------------------+
| [6] 푸터                                         |
+--------------------------------------------------+
```

## 3. 컴포넌트 트리 (개발 인수인계용)

> 개발자(또는 구현 AI)가 이 구조 그대로 컴포넌트를 만들 수 있도록 화면을 트리로 표현한다.
> 주석 번호는 레이아웃 [n], 유효성·동작 규칙은 POL ID를 그대로 단다.

```jsx
<{화면명}Page>
  <GNB />                          {/* [1] 공통 */}
  <PageTitle />                    {/* [2] */}
  <ContentList                     {/* [3] 정렬: 최신순, 20건/페이지 (POL-###) */}
    onItemClick={goto("SCR-###")}
  />
  <SideArea />                     {/* [4] */}
  <PrimaryButton                   {/* [5] 비활성 조건: {조건} (POL-###) */}
    onClick={...}
  />
  <Footer />                       {/* [6] */}
</{화면명}Page>
```
